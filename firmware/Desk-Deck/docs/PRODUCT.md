# 功能与工作流程

日期：2026-10-23。名称 Desk-Deck 为暂定名；本文件描述拟开发的首版，不代表设备已实现。

## 产品目标

将高频电脑操作放在一个独立、可触摸、可翻转的小控制台上。操作不用离开当前软件去寻找工具栏，设备不会因换姿态而误触发命令。重点是清楚、顺手、稳定；视觉效果服务于辨认和反馈。

首版基于现有 ESP-Mosaico，优先支持 Windows。目标为插入 USB 后作为标准键盘/媒体控制设备使用；免安装这一目标受 USB 技术验证结果约束。macOS、Linux 后续增加各自键位配置，不把 Windows 键位直接标为全平台兼容。

## 功能优先级

| 阶段 | 内容 | 完成标准 |
| --- | --- | --- |
| P0 · 必须 | USB 键盘组合键、Consumer 媒体按键 | 一次触摸只发一次，所有键均能释放 |
| P0 · 必须 | 4 套配置 × 每页 6 键 | 点击、滑动和翻转均能稳定操作 |
| P0 · 必须 | USB 就绪/未识别/休眠、锁定 | 不可发送时明确显示，不缓存待发操作 |
| P0 · 必须 | 设置与本机保存 | 亮度即时预览，取消回滚；振动与翻转可关闭 |
| P1 · 首版完善 | 电脑配置页 | 改名称、图标、组合键；导入导出、校验、写入、回读 |
| P1 · 首版完善 | 原子配置保存、恢复默认、异常恢复 | 无效配置不会使控制台失去控制 |
| 后续 | 自动识别前台软件、启动指定程序、显示真实音量 | 需要可选电脑助手，单独评估通信和安装体验 |
| 后续 | 宏序列、多页扩展、自定义图标 | 在按键释放与配置校验稳定后加入 |

首版不加入 AI 语音、天气、桌宠、账号系统、无线键盘或任意脚本执行。默认键位不包含关机、删除文件、保存密码等高风险操作；高级扩展另设边界。

## 典型流程

### 首次接入

1. 插入支持数据传输的 USB 线，显示“正在连接电脑”。
2. HID 完成枚举且主机未休眠后显示“USB 就绪”，六键可用。
3. 未识别时显示“仅供电 / 未识别”，提示检查数据线、端口和电脑；不把供电存在当作连接成功。
4. 默认进入“常用”。用户轻点复制，按下即高亮，松手提交；随后短暂显示“已发送 · 复制”。
5. 用户将设备稳定右转，界面对正视角并进入“开发”。这一步不产生按键。

### 日常操作

轻点 → 识别意图 → 提交单个按键组合 → 下一报告释放全部按键 → 短暂视觉反馈/可选轻振动。HID 没有软件执行结果，界面不能声称“复制成功”或“已保存文档”。

长按 600ms → 松手不发送 → 显示名称、键位与用途说明。触摸移动超过阈值取消原按键；横向滑动达到阈值后切页。锁定时只保留长按解锁入口，翻转不会解除锁定。

### 自定义配置

首版固件开发时优先通过官方 Iris RPC/本地网关提供配置服务，复用其通道所有权；是否支持浏览器直连必须先验证，不能与已有网关抢占 CDC。

建议电脑配置页流程：

1. 选择设备 → 查询产品 ID、协议版本和当前配置。
2. 选择场景和按键 → 填显示名 → 用按键录入器录入组合，或选媒体操作。
3. 查看预览和应用适用范围。每个操作限制为一组修饰键加一个普通键，或一个 Consumer usage。
4. 保存前校验 → 一次写入完整配置 → 校验并原子落盘 → 回读确认成功。中途失败仍使用旧配置。
5. 导出不含凭据的 JSON；导入必须验证 schema、产品类型、条目数和动作白名单。

当前网页原型提供缩减版编辑器：从 24 个默认动作中选择，修改名称、导出配置。它不连接真实设备，且不包含任意组合键录入或 JSON 导入。

## 默认配置与兼容边界

默认动作见 [default-profiles.json](../configs/default-profiles.json)，它也是原型数据源。开发页按 VS Code 默认绑定设计；用户改过电脑快捷键后需要同步改配置。办公页中的标签操作主要面向常见浏览器；同一个组合键在不同软件中可能有不同含义。

媒体按键只发送上一曲、播放/暂停、下一曲、静音和音量步进。不猜测音量百分比、不把“播放/暂停”改成未经确认的播放状态、不保证所有应用都响应媒体键。

## 资源与舒适度

- 设备主要插 USB 使用。屏幕静止时不持续重绘；无后台网络请求和无用途的动画。
- 触摸、IMU 和 USB 事件使用队列；存储、日志等耗时操作不堵塞 UI。
- 默认轻振动可关闭，默认不播放操作音。对外显示 USB 状态；电池状态沿官方 BSP 读取，未验证前不显示虚构数值。
- 交互目标：触摸按下到视觉反馈 <50ms；松手到 HID 入队 <30ms；稳定翻转到页面完成 <500ms。它们是验收目标，待实机测量。

## 首版验收边界

功能完整不等于发布完成。需验证 Windows 连接、全部默认键位、USB 插拔和休眠、重复触摸、滑出取消、长按不误发、翻转不误发、设置旋转、配置断电恢复及连续运行。具体顺序见 [IMPLEMENTATION.md](IMPLEMENTATION.md)。
