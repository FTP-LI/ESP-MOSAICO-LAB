# Trader-Lab V1.0 使用说明

版本 0.1.0-dev。基础实机验证见 HARDWARE-TEST-2026-10-27.md；长期运行与交易时段提醒仍需验证。

## 第一次连接

1. **设置 → Wi-Fi 网络**，等扫描后从下拉列表选择网络；也可点网络名称手动填写。
2. 点密码按钮，输入后按底部 **确定**。这一步只填写草稿；回到 Wi-Fi 页后点 **保存并连接** 才保存和连接。
3. 开放网络可留空密码，有密码的网络至少 8 字节。不支持网页登录认证或企业 Wi-Fi 证书配置。
4. 等待网络和时间同步。首页状态显示联网／校时结果，自选出现名称、价格和涨跌幅。无报价显示 `--`，不会使用演示价格。

密码遮挡，只保存到本设备 NVS，不写源码或诊断状态。本应用不直接读取其他应用的私有 Wi-Fi 设置。

## 自选

首页 **添加 ETF** → 输入六位代码或从示例目录选择 → **加入自选**。不需要 `sh`、`sz` 前缀，联网后识别名称。最多 64 只，每页 4 只。

点卡片查看详情，**移出自选** 后确认即可删除，同时删除其提醒。无法识别的代码保留等待状态，返回检查即可。首次使用按照 Genius-Trader-Lab 在 2026-10-27 保存的 47 只自选列表初始化，可自由删除。这是一次性导入快照，之后电脑端修改不会自动同步到设备。升级旧版时，已有提醒和列表外自选会保留；其余项目按导入顺序排列。

## 全球指数

点击底部 **全球指数**，用“亚太／欧美”切换：上证、深证、创业板、恒生、日经 225、韩国综合指数，以及标普 500、纳斯达克、道琼斯、德国 DAX、富时 100、法国 CAC40。

每项显示指数点位、相对昨收涨跌幅及北京时间。全球市场时区不同，收盘时间也不同；此页为公开延时报价，不标为逐笔实时行情。获取失败保留缓存，未取得数据显示 `--`；全球指数暂不设置到价提醒。

## 到价提醒

ETF 卡片 → **到价提醒**：选择“向上突破／向下跌破”，填写人民币目标价格（最多三位小数，例如 `4.250`），将状态切到“启用”，再 **保存提醒**。

启用后从新报价建立基线。若保存时价格已经在目标另一侧，不会补响；必须在连续的新报价中观察到真正跨越。交易时段默认约 30 秒取数，不是即时逐笔推送。

到价后弹窗、旋律和振动。点 **知道了 · 关闭本次提醒** 停止；无人确认时声音／振动最多 30 秒，弹窗保留。该规则已停用，若想继续监测，需要重新启用并保存。

断网、过期、时钟未同步、休市、来源切换和未知年份不补报。2026 年以后如显示“交易日历待更新”，更新日历固件后才恢复提醒。

## 显示与声音

- 正放／倒置对应 ETF 自选，右转／左转对应全球指数；底部两个标签也可切换，平放保持角度。设置页旋转时保留正在编辑的内容。
- **设置 → 显示与提醒**：亮度实时预览，返回撤销，保存才持久化；“日间主题”关闭即夜间主题。
- 音量 0–80%，0 为静音；振动单独开关。**试听旋律** 只试声音，不制造到价事件。

详情显示来源和原始报价时间。“最新报价”表示交易时段且未过期，“休市报价”是最近时段结束附近的数据。“连接失败／已过期”保留数字供查看，不用来提醒；“等待报价”表示尚无可信数据。观察曲线只画本次运行收到的连续报价，不是历史 K 线。
