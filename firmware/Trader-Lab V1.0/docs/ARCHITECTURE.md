# 独立联网实现

设备 Wi-Fi → SNTP 校时 → HTTPS 批量报价 → C 解析及完整性检查 → 有锁快照 → UI／到价提醒。电脑只负责构建、安装与可选调试。

| 部分 | 责任与隔离 |
| --- | --- |
| `network.c` Wi-Fi 任务 | 非阻塞扫描、连接状态、30 秒重连、扫描超时、SNTP；事件回调只发布状态 |
| `network.c` 行情任务 | 串行 HTTPS、最多 64 只 ETF + 12 项指数、正文 64 KiB 硬上限、5 秒单次 I/O 超时和读取总时限；不占用显示锁 |
| `model.c` | 字段／时间校验、GBK 名称、价格千分位、日历／时效、跨价状态机；同一 C 实现在主机测试 |
| `main.c` | LVGL、编辑草稿、IMU、提醒、异步保存请求；亮度、旋转、NVS 写入均在显示锁外 |
| `audio.c` | 独立任务、长度 1 的队列、可取消播放；只初始化扬声器 TX，关闭后停止 DMA，不打开麦克风 |

配置变化带请求版本号，旧请求不能覆盖新自选。每只标的独立失败，部分缺失保留旧报价但标记连接失败。UI 修改只在显示锁内；共享数据先复制为短快照，不持锁进行网络／存储操作。

## 报价与节流

主源：`https://push2.eastmoney.com/api/qt/ulist.np/get`，字段 `f12/f14/f2/f3/f18/f124`、`fltt=2`。备用：`https://qt.gtimg.cn/q=...`，解析 GBK 名称、价格、昨收、百分比和北京时间戳。均验证 TLS 证书，无内置私人密钥。

2026-10-26 在电脑完成两只 ETF 实际请求，核对价格、昨收和时间一致，并将原始响应交给固件 C 解析器复测。2026-10-27 基础固件已在设备验证 DNS、TLS、SNTP 和真实 ETF 报价。 这些是公开端点，非本工程签约数据源；403／429 等不会通过换域名规避，主源进入 10 分钟冷却。

交易时段约 30 秒刷新，休市约 300 秒，失败退避至 300 秒。手动刷新合并在途请求且间隔至少 5 秒。行情不写闪存，每次开机重新取数；运行中保留 RAM 旧报价并显示质量状态。

## 全球指数与自选迁移

`watchlist_seed.c` 保存 47 只自选的代码和名称，不包含持仓、交易、账户信息。旧 `config_v1` 先验证再迁移到 `config_v2`：保留网络与偏好、匹配代码的提醒、列表外旧自选；保留旧键以供回退。新配置上限 64，提醒位图采用 64 位，操作编号与详情索引区间不重叠。

`global_market.c` 批量解析腾讯 12 项指数；标准格式取价格/昨收，全球简表格式用价格减涨跌点数恢复昨收，再核对百分比。美国标准格式时间按纽约夏令时换算，全球简表原始时间为北京时间，所有 UI 时间统一为北京时间。校验精确代码、价格、昨收、时间和可用字段的涨跌幅一致性；未来、过老和倒退报价拒绝替换。全球页明确标示公开延时数据，保留原始时间，不套用沪深开市状态或触发 ETF 提醒。

全球 12 项合并为一个 HTTPS 请求，一轮后等待约 120 秒。ETF 和全球请求共用单一工作任务，避免 TLS 并发内存峰值。网络快照、历史缓冲、JSON 节点及 TLS 分配放入 PSRAM，诊断不在任务栈分配 64 项快照。上游公共接口无稳定性保证，失败显示缓存而不合成价格。

## 数据质量与提醒

价格、昨收必须为正且在范围内，代码为 ETF 候选、返回名称包含 ETF。百分比与价格／昨收冲突时整条拒收。价格使用整数千分位，目标不接受科学计数法、负数或超过三位小数。

状态为等待报价、等待校时、交易日历待更新、连接失败、报价已过期、休市报价、最新报价。保留供应商时间；未来超过 5 秒、过期超过 120 秒、日期倒退、请求失败或时钟未经同步均不触发提醒。

2026 闭市日期参考[上交所](https://www.sse.com.cn/disclosure/dealinstruc/closed/)和[深交所](https://www.szse.cn/disclosure/notice/general/t20251222_618087.html)。双休日即使调休上班也不交易；未知年份禁止提醒。午休、收盘仅将最近交易时段结束附近的报价标为休市报价。

每只自选一条规则。首次启用、重启、断网、来源切换或超过 120 秒断档后重新建立基线；不因为当前价已经超过目标就补报。连续两次有效新报价跨越才触发，重复时间戳不重复处理。触发与停用状态写入 NVS，声音／振动最多 30 秒，确认后需手动重新启用。轮询间短暂越过后返回可能无法发现，不承诺逐笔覆盖。

## 资源与边界

480×480 RGB565；16/20 像素字体覆盖 GB2312 常用汉字并开启 LVGL 大字库索引。最多 64 自选、每只 60 个本次连续观察点，换来源和长断档清空曲线。IMU 稳定 400 ms 后旋转，平放保留角度；编辑时不切业务页。

主循环 25 ms，Wi-Fi 最小 modem 省电，静态 UI 按数据变化重绘，无实验性降频或显示时钟改动。实际耗电、发热和触控响应需新固件实测。

尚未接入历史 K 线、全市场广度、复杂评分、新闻、交易／券商账户、云推送或 AI。设备必须开机联网且取得可靠新报价才能提醒。
