# 功能与界面规划

原规划日期：2026-10-25。用户已选择独立联网，电脑关闭后也能看行情。2026-10-26 已实现第一轮联网、自选与到价提醒；准确实现范围和验证状态见 README、ARCHITECTURE 与 VERIFICATION。以下表格保留产品路线，历史 K 线、涨跌幅提醒、可选铃声、静音时段及全市场概览尚未实现。

## 首版优先级

| 优先级 | 功能 | 设备上的表现 |
| --- | --- | --- |
| P0 | Wi-Fi 配置、校时、连接反馈 | 引导页展示连接中/成功/失败，可返回重试；联网任务不阻塞触控 |
| P0 | ETF 自选 | 先支持最多 12 只、每页 3 只，显示名称、代码、价格、涨跌和行情时间 |
| P0 | 单标的图表 | 大号价格、最近日线收盘趋势，后续增加真实 OHLC 蜡烛图；清楚标注周期和复权口径 |
| P0 | 自定义提醒 | 到价、涨跌幅阈值；可选铃声/振动、静音时段、确认及重新启用 |
| P0 | 数据质量和断网 | 保留最近快照并标“缓存”，显示原行情时间；缓存不触发到价提醒 |
| P1 | 市场概览 | 宽基指数与涨跌家数，需要先验证独立数据源和时间口径 |
| P1 | 轻量指标 | 同口径 MA/BOLL 等在取得足够历史后计算，不伪造预热区数据 |
| P1 | 资讯与披露 | 少量标题、来源和发布日期；不在小屏承载全文 |
| 后续 | 综合分析、机构追踪 | 按资源与数据可用性逐项迁移；不承诺在首版复刻完整桌面分析 |

首版不包含下单、券商账户、自动交易或个人持仓分析；本次未读取 Analysis 的个人档案。

## 480×480 四页

| 页面 | 布局 | 操作 |
| --- | --- | --- |
| 自选 | 顶部行情状态；三行自选卡片；底部四页导航 | 点卡片打开图表，上下翻自选组 |
| 图表 | 标的与价格；居中的趋势/日线图；行情日期 | 切换标的和周期，点图查看数据 |
| 市场 | 两个指数卡片、上涨/下跌比例、数据质量 | 点指标看来源和实际日期 |
| 提醒 | 当前规则、提醒状态、确认按钮 | 编辑阈值、开关提醒；确认后显式重新启用 |

设备转动时文字跟随；“翻转切换页面”为可关闭选项，默认姿态建议正放自选、右转图表、倒置市场、左转提醒。平放保持前一方向。设置和阈值编辑中只旋转屏幕，不自动离开当前页面。

采用深色底、低饱和青色交互色，大号价格与固定行高。涨跌同时显示符号、数字和颜色，可设置红涨绿跌/绿涨红跌；不能仅靠颜色判断。每页保留来源/时效入口，禁止用请求时间替代行情时间。

## 提醒流程

选择标的 → 选择到价或涨跌幅 → 滚轮调整数值 → 选择铃声/振动 → 保存 → 等待有效新报价跨越阈值 → 提醒 → 轻点确认。

启用时已经越过阈值，先提示并建立基线；不补发过去的提醒。每条规则单次触发后进入待确认，确认后默认停用，需手动重新启用。网络重试、刷新页面和重复报价不会再次响铃。休市、时钟未同步、报价缺失/缓存/过期时暂停监测，并显示原因。

## 设置分组

1. 网络：连接状态、Wi-Fi、更换网络、校时状态。
2. 自选：内置少量分类目录及代码输入，确认名称后加入；不能让用户猜交易所前缀。
3. 显示：日间/夜间/自动、切换时间、亮度实时预览及返回撤销、自动调暗。
4. 提醒：铃声、音量试听、振动、免打扰时段。
5. 更新：刷新频率、数据源状态、最后成功时间、缓存说明。

设置页面分步呈现，大触控区域；实时预览与持久保存分开。设备本身可以完成基本配置；手机网页配置留待后续。

## 原型范围

当前可点击四页导航、自选卡片、图表标的切换、四向模拟、日夜主题、模拟断网、提醒触发与确认。数据全部合成，无真实联网；原型中的“模拟触发”是展示按钮，不代表阈值计算已经实现。
