# 界面与交互设计

## 视觉方向

采用石墨深色底、低饱和场景色、线条图标和清晰的大文字，避免沿用 Time-Tick 的天气/桌宠装饰。页面从常用的薄荷绿，切换为开发的蓝、办公的暖杏、媒体的紫；文字和图标同样表示场景，不依赖颜色单独区分。日间模式使用浅灰白背景。

工作区外的网页控制面板仅用于演示，设备上只显示 480×480 屏幕区域。原型的线条图标为本工程内自绘 SVG，不依赖图标 CDN 或远程字体。

## 480×480 首页

| 区域 | 设计尺寸/内容 | 理由 |
| --- | --- | --- |
| 外边距 | 四边 24px | 避开屏幕圆角、手指边缘误触 |
| 顶部 | 60px：小项目标识、场景名、USB 状态、锁定/设置 | 名称是切页入口；图标触控区至少 44×44px |
| 说明行 | 36px + 12px 间距：用途说明、01/04 页码 | 一眼理解当前场景 |
| 六键 | 3 列×2 行；间隔 10px；约 137×135px/键 | 拇指可触，避免密集九宫格 |
| 按键内容 | 32px 图标、17px 名称、10px 键位 | 名称优先，键位用于确认 |
| 底部 | 44px：最近操作、页码点 | 无冗余功能栏；反馈最多一行 |

具体尺寸由原型 CSS 自动计算。小屏浏览器只是缩小预览；实际固件按完整 480×480 设计，不能把桌面网页的侧栏搬进设备。

## 页面结构

```text
首页（常用 / 开发 / 办公 / 媒体）
  ├─ 点击场景名 → 场景选择 → 回首页
  ├─ 点击按键 → 已发送反馈 → 回静态首页
  ├─ 长按按键 → 操作说明 → 返回 / 电脑端编辑
  ├─ 设置 → 亮度、轻触振动、翻转切页 → 保存 / 返回
  └─ 锁定 → 长按 0.8 秒解锁 → 回原页面
```

操作说明页在原型里提供“编辑此按键”，聚焦网页侧栏。固件可改为显示“在电脑配置页编辑”与连接方法，不在小屏上要求用户输入复杂键位。

## 交互规则

| 输入 | 结果 | 不应发生的行为 |
| --- | --- | --- |
| 轻点并在按键内松开 | 发送一次组合键/媒体键 | 连续重复发送或保留修饰键 |
| 按住 600ms | 显示操作说明 | 松手后追加单击 |
| 手指移动 >12px | 取消当前按键 | 拖动途中发键 |
| 横向滑动 >64px，水平明显大于垂直 | 前/后一页 | 同时触发起点/终点按键 |
| 四向稳定翻转 | 屏幕旋转、选择对应页面 | 自动发送任何按键 |
| 屏幕朝上或朝下平放 | 保留之前角度和页面 | 创建第五套操作或启动计时 |
| 设置、详情或选择页中翻转 | 只旋转画面，保持页面和草稿 | 弹层关闭、字段丢失或误切场景 |
| 锁定状态翻转/点击 | 维持锁定 | 发送、切页或自行解锁 |
| 长按解锁 0.8 秒 | 回到原页面 | 短按解锁 |

阈值为初稿，后续以真实触控和 IMU 数据调整。原型的方向按钮代表“已经稳定”的姿态事件，文字始终按观看方向对正；不是物理 IMU 或真实屏幕旋转测试。

## 连接状态

| 状态 | 状态栏 | 按键 | 恢复方式 |
| --- | --- | --- | --- |
| 正常 | USB 就绪 | 可用 | 无 |
| 仅供电/尚未枚举 | 仅供电 / 未识别 | 降低对比度、禁止发送 | 确认数据线/电脑，待枚举完成 |
| 主机挂起 | 电脑休眠 | 禁止发送 | 主机恢复后重新点击；首版不默认唤醒电脑 |
| 锁定 | 覆盖锁屏说明 | 禁止发送 | 长按解锁 |

输入都不排队等待重连；USB 恢复后提示“请重新点击”。设备无法确认目标软件收到或完成操作，因此反馈固定为“已发送”；原型明确写“已模拟发送”。

## 动效与亮度

按下缩小到 97%，松手反馈约 180ms；页面切换可使用 120ms 局部淡入，低功耗或性能不够时直接切换。无持续呼吸灯、扫描光、背景粒子。原型关闭循环动画，支持浏览器减少动态效果偏好。

亮度设置有 52px 高触控轨道与 36px 拖柄，支持点击轨道和键盘微调。保存才提交；返回、关闭或 Escape 均回滚，不保留会被上级保存误提交的草稿。原型只模拟明暗，真实 PWM 要沿 BSP 已验证路径实现。

## 易用性约束

所有重要状态使用中文；名称最长八个字符，但实际设备优先 2–5 字，保存前检查换行/溢出。图标均有文字，键位不作为唯一提示。黑白主题均检查可读性。原型支持键盘焦点、Enter/空格、Escape、弹层焦点循环；默认不拦截浏览器全局快捷键。
