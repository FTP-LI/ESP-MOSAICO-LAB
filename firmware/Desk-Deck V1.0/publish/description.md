# Desk-Deck｜桌面快捷控制台

把常用操作，放到手边。

Desk-Deck 将 ESP-Mosaico 变成一块 USB 快捷键面板：六个大触控按钮，四套工作场景。转动设备，屏幕与场景随之切换；轻点按钮，把快捷键发送给电脑当前正在使用的软件。

**0.1.0-dev 开发预览版 · Windows · ESP32-S31 版 ESP-Mosaico**

## 四个方向，四套场景

| 姿态 | 场景 | 默认操作 |
| --- | --- | --- |
| 正放 | 常用 | 复制、粘贴、截图、撤销、重做、显示桌面 |
| 右转 | 开发 | 运行/停止调试、终端、格式化、全局搜索、命令面板 |
| 倒置 | 办公 | 保存、查找、全选、新建标签、恢复标签、切换窗口 |
| 左转 | 媒体 | 上一曲、播放/暂停、下一曲、静音、音量减/加 |

开发页采用 VS Code 在 Windows 上的默认快捷键；其他软件与自定义键位可能不同。媒体按键是否生效取决于电脑和播放器。

## 操作简单，反馈明确

- 轻点发送一次，长按只查看操作说明。
- 设备稳定翻转后切换场景，也可左右滑动或点底部标签。
- 屏幕朝上平放时保留上一方向；翻转本身不会发送快捷键。
- 设置页同样跟随旋转，提供亮度即时预览、返回撤销、日间主题、轻振动与翻转切页开关。
- 临时离开时点击锁定，回来长按解锁。
- USB 未就绪时禁用按键；断连或主机挂起时清空待发送操作。

## 需要准备什么

ESP32-S31 版 ESP-Mosaico、支持数据传输的 USB-C 线和 Windows 电脑。安装基于 Vibe Mode 0.2 / Recovery ABI 2，实测基础固件为 0.2.1。运行时不需要 Wi-Fi、云账号或电脑助手。

## 开始使用

1. 安装本应用后，用 USB 数据线连接电脑。
2. 等待屏幕显示「USB 就绪」。
3. 在电脑记事本中选一段测试文字，轻点「复制」，再在目标位置点「粘贴」。
4. 转动设备选择场景，或通过底部标签直接切换。

同一设备安装后会替换原来运行的应用。安装包保留官方恢复分区及已有 NVS 数据；可以进入 Vibe Mode 重新安装其他应用。

## 当前验证与限制

已完成官方安装与健康核验、Windows 键盘/媒体 HID 与双 CDC 共存、真实截图、24 步旋转/亮度组合、恢复通道和重启检查。用户已确认复制/粘贴、修正后的正放/倒置及设置页触控正常。

本版使用四套固定按键。仓库中的网页原型仅用于演示，**修改网页配置不会同步到实物**；远程配置、宏和应用自动识别尚未接入。媒体及全部 24 项动作的逐项兼容性、长期稳定性、断连/挂起恢复、功耗与温升仍待完整验收。设备显示「已发送」只代表 HID 报告完成，不保证目标软件执行成功。

四场景配图均来自本版本的真实设备截图，外框和图文为展示排版。
