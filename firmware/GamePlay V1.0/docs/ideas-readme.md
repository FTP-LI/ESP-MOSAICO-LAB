# GamePlay V1.0（开发中）

这是面向 ESP-Mosaico CoreBoard V1.2 / ESP32-S31 的非官方开源游戏机项目。计划复用主机的 480×480 屏幕、扬声器和电源系统，配合自研实体按键板和掌机外壳，先验证 FC/NES，再推进 GB 与 PICO-8 兼容方案。

**本页目前是本地资料草案，没有可供安装的游戏版本。** 当前源码实现了色块显示、测试音、触摸与板载/外接按键诊断，两种诊断配置已编译；游戏核心、存档和外接手柄实测尚未完成。官方 Vibe 基础固件的烧录成功不代表本项目游戏功能已通过验证。

## 硬件与操作

目标主机是 CoreBoard V1.2，底板实物版本与接口配合仍需核验。外接手柄规划方向、A、B、Start、Select、Menu 九个逻辑动作。自研按键板不是平台预设的摄像头、以太网或电池子板。

当前诊断页可通过屏幕 TONE/COLORS 和板载 AI/BOOT 测试声音与颜色；实体手柄配置属于实验功能。按键板连接方向、电气与封装未核验完成前，不可按草案直接接线或生产。游戏按键和菜单操作将在首个游戏版本验收后补充。

## 安装与兼容性

目前不提供游戏安装步骤或下载包。源码已接入保留 Vibe 的应用布局与官方 `.irisfw` 打包框架，但新应用尚未完成完整构建、实际打包或设备验收。首个候选版本须完成包检查和安装/恢复测试，再填写最低 Vibe 版本、安装方法和实测硬件组合。旧普通单应用布局的诊断镜像不能用作该安装包。

FC、GB、GBC 和 PICO-8 均尚未在本套件上验证，不承诺所有游戏兼容。游戏导入、存档、续航及性能指标仍待实现和测试。本项目不随草案提供 ROM、BIOS 或个人卡带库。
