# 发布素材

将实机封面、截图或演示图放在本目录。当前没有真实游戏截图，故元数据的 covers 仍为空，不使用占位图片冒充运行效果。

封面支持 PNG/JPEG/WebP/GIF，最多 9 张、每张不超过 10 MiB。在 mosaico-ideas.json 中填写应用目录相对路径，例如 publish/assets/cover.png，文件存在后再添加。

网页说明引用的本地资料会由官方 CLI 发现并上传；显式 resources 必须被网页说明引用。独立下载资料用 attachments。所有路径必须留在本应用目录内，不能使用绝对路径、反斜杠或 ..。

网页素材不会写入设备 Flash；将来需要独立 Flash 数据镜像时，另建镜像生成规则并注册官方打包目标。
