## 使用行为

- ESP-Mosaico / ESP32-S31，USB Audio Class 2.0，固定 48kHz、16-bit、单声道输入。以 Windows 10/11 为首要验收平台，保留 Iris 双 CDC 管理通道。
- 主屏显示实时输入峰值及 RMS 电平（dBFS，不是声压级）、峰值过载提示、USB 已连接/电脑正在收音状态。
- 设备增益 0–42dB，每步 6dB，默认 24dB；与固定 ES8311 驱动支持的档位一致。电脑 UAC 音量为独立数字衰减 -60–0dB，默认 0dB。屏幕区分两者。
- 设备静音或电脑静音任一有效时，USB 输出和新录音均为零；输入电平仍可观察。开机恢复设备静音和增益设置，录音不自动开始。
- 最长 30 秒，保存最近一段。录制时 USB 麦克风继续工作；手动停止或达到上限后保存。录音内容是当时送往 USB 的声音，含静音和主机衰减。
- 保存至现有 NAND LittleFS 的独立 `/nand/mic-lab/` 目录。临时文件写完、fsync、关闭、读回验证后原子替换旧文件。新录音保存失败时保留旧文件，并允许重试保存当前 RAM 录音。
- 只有界面显示“已保存”才代表本段持久化完成。录制/保存过程中断电时，不保证新片段保留；此前成功保存的片段应仍可恢复。
- 回放从设备扬声器输出，默认音量 35%，可停止；回放期间停止麦克风采集，USB 连续输出静音。停止扬声器后设置短暂静音保护，避免尾音被重新录入。
- 上电读取并校验已保存片段；缺失属于正常空状态，损坏/挂载失败明确提示。任何普通错误均不得格式化 NAND。
- 所有存储操作在独立任务进行；录音缓冲放 PSRAM，I2S DMA 和 USB 缓冲留内部 RAM。音频驱动由唯一音频任务管理。

## 首版范围

本版是可构建、可通过官方更新包安装的开发版。电脑回归、固件构建和实机验收分别记录。实机安装会替换当前运行应用，须在成品可审查后进行；当前阶段不自动刷写设备。

不含无线、AI 降噪、阵列拾音、32-bit 浮点、电脑扬声器输出设备、录音列表、长时录音、导出工具或墨水屏。保存只保证本固件正常重启/断电后恢复，不承诺在用户格式化 NAND 后恢复。

## 方案选择

用户选择直接复用板载采集和 USB，而非先做无线或外接音频板。短录音原建议 RAM 保存，用户改为断电保存；采用官方现有 LittleFS 挂载后写独立文件，避免原始 NAND 裸写或调整 NOR 分区。前期不增加 TF 卡。

## 界面

480×480 单屏录音台：浅灰蓝底 `#e9eef3`、深蓝文字 `#172b40`、蓝色控制 `#28649d`、青色正常电平 `#218a78`、琥珀高电平 `#b77919`、红色静音/过载 `#bc394a`。使用思源黑体小子集与清晰数字；输入电平为视觉主体，下方增益、静音和录音/回放按钮固定位置。20Hz 刷新数据，不重建整个界面。状态和文字共同表达颜色含义。

## 验收

1. Windows 枚举单声道 48kHz 输入与双 CDC；Iris 状态/日志/恢复入口可用。
2. 电脑实际录音有人声，无左右通道误读、持续爆音或周期性断音；持续 10 分钟并记录欠载/丢弃计数。
3. 设备及主机静音均输出数字零，解除静音无旧缓冲声音泄漏；增益变化可听且显示一致。
4. 录音自动在 30 秒停止，录制期间 USB 连续；正常保存、重启、拔电后可回放。
5. 保存中断、存储空间不足、损坏文件不显示成功，不破坏上一份已保存录音或其他 NAND 文件。
6. 回放期间 USB 静音、无扬声器回授；停止后恢复采集，未启动回放时扬声器静音。
7. USB 拔插、主机关闭输入/挂起后重新打开、快速连续按钮操作均不崩溃或卡住。
