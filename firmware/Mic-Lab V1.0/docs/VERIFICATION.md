## 固件与更新包

固定 ESP-IDF / ESP32-S31 构建及官方 `system-update-bundle` **PASS**。应用 1,194,432 字节；更新包 711,320 字节。构建包含真实 NAND BDL/LittleFS 后端及 UAC 类驱动。SDK 提示本机 configdep 未安装与部分 Kconfig 过时语法，但构建未报错。

- 应用：`build-idf62/mic_lab.bin`，SHA-256 `75dc62b13a0d075bfe9da374c997521172afeb537051871128178a16aea76410`。
- 更新包：`build-idf62/mic_lab-system-update.irisfw`，SHA-256 `0f3a814604c291c5680574799c7bd058b37e8e68d4c57812c6a9b82b32003baa`。
- 包含 `manifest.json`、`partition-table.bin`、`ota_0.bin`；核对了各条目长度和 SHA-256。应用目标仍为 `0x210000`，分区表仍为 `0x8000`，包内不含 NAND 数据或 NVS 镜像。最低 recovery 版本为 `0.2.0`。
- 机器可读记录：[BUILD-ARTIFACT.json](BUILD-ARTIFACT.json)。构建产物在本机保留，不提交 Git。

以上只确认可构建和包内容正确，未进行设备安装、Windows USB 枚举、实际人声录制或断电恢复验收。

## 实机验收清单（均待执行）

| 场景 | 操作与通过条件 |
| --- | --- |
| 安装/恢复 | 官方 Vibe Mode 安装更新包；核对应用版本与健康状态、双 CDC、截图/RPC/恢复入口 |
| USB 枚举 | Windows 识别单声道 48 kHz 输入；录音软件打开后才显示正在收音，关闭或重连后不残留 |
| 连续收音 | 电脑录制至少 10 分钟；检查人声、波形、间断/爆音、内存与诊断计数，包含录音保存期间 |
| 增益/静音 | 逐个 6 dB 档位核对；设备与主机静音分别验证零采样，恢复时没有旧声音重播；允许已排队的有限 USB 延迟 |
| 录音/回放 | 短录音与 30 秒录满，尾音完整；回放期间电脑静音，停止后恢复，无扬声器回授 |
| 断电保留 | 录制明确口令，显示已保存后关闭设备电源，再启动回放同一内容；USB 拔线但电池继续供电不算断电测试 |
| 保存中断 | 先保存 A，再录制 B；B 保存期间断电，重启应得到完整 A 或完整 B，不能得到损坏片段；同时确认其他 NAND 数据完好 |
| 存储不足/损坏 | 在可恢复的测试介质或备份后模拟；不得格式化，不能误报成功；旧保存文件保持，当前 RAM 可重试 |
| 操作与重连 | 连续点击、输入关闭/打开、USB 拔插、挂起/恢复，界面与音频无死锁；低内存和存储错误要显示明确状态 |

USB 短包计数包含启动或主机额外轮询，而且不能检测所有驱动边界欠载。最终连续性以实际电脑录音和声音检查为准。文件系统断电一致性通过软件协议降低风险，但不能用电脑文件测试代替真实 NAND 断电测试。
