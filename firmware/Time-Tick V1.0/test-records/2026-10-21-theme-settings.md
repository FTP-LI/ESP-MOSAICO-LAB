# 可配置昼夜主题与仓库整理（2026-10-21）

## 范围与操作

入口：“设置 → 系统 → 显示 → 主题与时段”。支持日间、夜间、自动，自动模式默认20:00进入夜间、05:00恢复日间，两个时刻均可用小时/分钟滚轮修改。区间包含开始、不包含结束，支持跨午夜或同一天区间；自动模式拒绝相同的开始/结束时间。手动模式保留时段值，滚轮禁用，改回自动即可继续调整。

选择后立即预览，返回取消本页主题修改，再在父页面保存也不会提交已取消的主题。直接保存写入设备配置；首次引导中“应用”回到显示步骤，最终完成引导后统一保存。保存失败保留草稿供重试。主题改变只更新样式和场景光照，不重建当前页面，不改计时截止时间和已保存亮度。天气、呆猫受光同步日间/夜间；时钟仍是真实当地时间。

设置schema从5增至6，兼容旧1–5并保留Wi-Fi、地点、方向、校准、铃声与亮度。原有配置只在用户保存时持久化新结构。自动模式使用设备所选时区；时钟尚未有效同步时沿用当前主题，手动日间/夜间仍能立即生效。
