# 中英文、首次引导与桌宠验证（2026-10-20）

## 本次实现

- 共享 LVGL UI：中文/英文欢迎页、四步首次引导、分组设置页与主画面。
- 网络页支持手动 SSID/密码、显示密码、连接状态和明确的离线入口；系统页包含伙伴、亮度、时区、城市和振动开关。字母/数字屏幕键盘保持可用。
- 猫、狗、小鸡为原创代码绘制，支持待机动作、专注/到时状态和点击爱心。
- 配置 schema 2：增加语言、伙伴、亮度、振动及首次设置完成标志。加载 v1 时保留网络与计时/校准数据，并进入一次新引导。
- 保存采用命令处理结果通知；队列接收不等于保存完成。保存失败留在表单，可重试；返回撤销普通设置编辑。

## 验证结果

`cmake --build build-pc --parallel 8` 成功，`ctest --test-dir build-pc --output-on-failure` **4/4 通过**：

1. `core`：既有姿态、校准、计时策略及边界测试。
2. `settings`：默认值、新字段边界、完整数据往返与 v1 数据迁移。
3. `preview_smoke`：首次引导、网络密码校验/模拟连接、伙伴选择、中英文保存、保存失败重试、取消编辑、旋转/天气/告警及计时预设校验。
4. `preview_configured`：已完成设置的启动跳过引导，主界面及设置行为正常。

VS Code F5 启动真实 SDL 窗口，实际验证中英文欢迎页切换、中文离线引导进入主页，以及点击猫猫出现爱心。最终预览重新停在欢迎页，便于从头体验。

官方 ESP-IDF 命令 `idf.py --preview --no-ccache --no-configdep -B build-idf62 build` 编译通过；本轮设备编译由终端直接调用官方 `idf.py`，PC 预览则在 VS Code F5 中启动。

- 镜像：`build-idf62/time_tick.bin`，**2,031,680 字节**。
- SHA-256：`470273571814c58a0af0a3b7d4b405016075dea26f787e7ae757f76977b62a0d`。
- `python publish/validate.py`：官方元数据、工作区、分区布局与版本校验通过；真实发布截图、`.irisfw` 检验和实机测试仍待补齐。
- 通用 factory 分区大小警告仍存在，继续遵循本项目 Iris / ota_0 安装方案。
