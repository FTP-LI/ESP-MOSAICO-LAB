# Wi-Fi 配网与互动小院验证（2026-10-20）

## 参考与实现

参考本地官方工程：`examples/esp-mosaico-vibe/submodule/esp-mosaico-utils/esp-mosaico-recovery/firmware/recovery/main/vibe_ui.c`（进入 Wi-Fi 页触发扫描、网络列表、密码页面、大小写/符号键盘）和 `factory_network.c`（异步扫描结果、去重、连接状态）。只参考交互和 API 用法，没有改动官方示例，也没有把恢复固件作为应用模板。

应用新增 `main/ui_network.*` 与 `ui_garden.*`。普通网络通过列表选择；密码键盘常驻数字行，开放网络免密码，保留手动隐藏网络、刷新与错误重试。实际驱动使用 ESP-IDF `esp_wifi_scan_start(..., false)` 和扫描完成事件，最多 24 个结果，按 RSSI 排序并去重；扫描记录在堆上分配，避免挤占默认事件任务栈。天气 HTTPS 与 Wi-Fi 控制分开运行。

主画面将伙伴空间从 108×104 扩大到 448×208，增加散步、点地面移动、摸头、喂食与追球。时钟改为 52 px 灰度抗锯齿数字，场景增加天空层次、瓦片、窗框、池塘、树叶、花草和阴影。16 px 字体增加 GB2312 汉字回退以显示常用中文 SSID。

## PC 验证

`cmake --build build-pc --parallel 8` 成功，`ctest --test-dir build-pc --output-on-failure` **4/4 通过**。

- 扫描、空结果、扫描失败后刷新、开放网络、错误密码后重试。
- 实际 LVGL 键盘的数字、大小写、符号、退格输入；键盘坐标位于 480×480 视口内。
- 连接过程中取消恢复原网络；隐藏网络表单返回；保存成功/失败重试与取消设置。
- 使用可控 LVGL 时钟推进动画，验证喂食/追球到达后才显示相应反馈。
- 既有中英文、首次引导、配置迁移、全部旋转、离线/天气/告警和计时边界回归。

通过 VS Code F5 启动真实 SDL 窗口，实际验证中文网络名、列表触摸拖动、点选网络、数字键输入、取消返回和离线引导；观察小院移动和喂食。实窗检查发现的列表文字重叠、键盘默认对齐越界与按钮裁切已修正。最终窗口保留中文主界面供体验。

PC 网络和天气都是明确标注的模拟数据，不扫描电脑网络；`wrongpass` 是模拟失败用的测试密码。控制窗口的 Cycle scan 可在正常/空列表/失败之间切换，随后点击网络页刷新。PC 设置仅当前进程会话有效。
