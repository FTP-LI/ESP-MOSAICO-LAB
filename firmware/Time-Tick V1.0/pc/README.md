# Time-Tick 电脑预览

电脑上运行 480×480 设备画面，用鼠标模拟触摸，旁边的控制窗口模拟翻转。PC 与设备使用 `main/sources.cmake` 中同一套 LVGL 页面、动画、养成模型和计时逻辑。设备固件仍由官方 ESP-IDF 扩展编译。**电脑预览不需要连接或烧录设备。**

## 从 VS Code 启动

1. 选择“文件 → 打开文件夹”，打开 **`firmware/Time-Tick V1.0`**，以加载本项目的运行配置。
2. 首次使用准备下方依赖。当前电脑已配置，普通启动无需重新安装 SDK 或删除缓存。
3. 打开“运行和调试”，选择 **Time-Tick: 电脑预览（GDB）**，按 **F5**。终端依次执行“配置电脑预览”“编译电脑预览”；成功后出现设备画面和中文模拟控制台。被遮住时用 Alt+Tab 找回。
4. 设备窗口显示七页引导：**语言 → 网络 → 伙伴 → 显示 → 到时提醒 → 天气 → 方向校准**。预览可选“离线继续”；点伙伴图片或名字会播放玩球动作。PC默认已有虚拟校准，可直接完成进入小院。天气页提供“联网定位当前位置”“搜索城市”“常用城市”；这三个入口使用电脑真实网络查询地点，无需配置模拟Wi-Fi。点选候选后继续引导，天气数值仍为示例。系统设置只保存本次会话，重启会再次显示引导。
5. 在主屏观察呆猫自主散步，或点草地召唤。控制窗口点“下一种天气”查看雨滴/涟漪、飘雪、雾带、星光和不同活动节奏；雨披、围巾、扇子使用完整的停留姿态。点“陪伴”播放六帧进食、玩球、擦洗和睡眠动作。进食约1.8秒，玩耍/洗澡约2.7秒，动作播完后才能再次互动。满状态仍可互动，互动可唤醒伙伴，不扣其他状态，也不需每日维护。
6. **正常退出：关闭设备预览窗口**，保存最后的被动状态变化。再在 VS Code 按 **Shift+F5** 结束残留调试会话。修改代码后重新按 F5，先增量编译再运行新版本。强制停止调试可能来不及保存最后一分钟的被动变化。

不使用调试器时，选“终端 → 运行任务 → **Time-Tick: 启动电脑预览**”，同样自动配置、编译并运行。回归检查使用 **Time-Tick: 测试电脑预览** 任务，包含九组核心测试与八个无窗口界面测试（共17项），包括地点定位确认、城市候选、查询失败/空结果、取消、坐标输入、呆猫的六类天气行为、电量状态与省电边界、动作优先级和计时切换。自动回归使用固定地点样本，不调用网络。

夜间主题与控制台时段模拟联动：选到夜晚后，设置、计时、键盘、下拉菜单和成就一同切为深色；白天恢复原配色。默认自动时段为当地20:00–次日05:00，可在“显示 → 主题与时段”调整到分钟，并选择固定日间/夜间；预览配置仅在本次会话保存，实机保存至NVS。当前回归为17项（9组核心、8组界面），其中 `--smoke-theme` 检查跨时段保留草稿与输入光标、未变化画面不额外刷新、夜间圆盘和翻转停铃。

## 首次准备环境

- Windows x64，MinGW-w64 GCC/G++/GDB，CMake ≥3.24、Ninja。`gcc`、`g++`、`gdb`、`cmake`、`ninja` 需在 VS Code 的 PATH 中；修改 PATH 后重启 VS Code。
- F5 使用 Microsoft **C/C++** 扩展；`.vscode/launch.json`、`tasks.json` 已提供配置。
- 先通过官方 ESP-IDF 扩展解析本工程依赖，得到 `managed_components/lvgl__lvgl`，锁定 LVGL 9.5.0。无需烧录。
- CMake 首次配置自动下载固定 SDL2 2.32.10、校验 SHA-256，并复制 `SDL2.dll` 到 exe 旁。无需安装 SDL 到系统目录。

在**本项目目录**打开终端，等价命令如下。每条成功后再执行下一条；编译失败时不要直接运行旧 exe。

```powershell
cmake -S pc -B build-pc -G Ninja -DCMAKE_BUILD_TYPE=Debug -DCMAKE_C_COMPILER=gcc -DCMAKE_CXX_COMPILER=g++
cmake --build build-pc --parallel 8
ctest --test-dir build-pc --output-on-failure
.\build-pc\time_tick_preview.exe
```

双击 exe 只运行上次编译结果，不会更新代码。首次编译包含 LVGL 和资源，后续保留 `build-pc/` 可增量编译。

需要直接检查主界面时，可在构建后运行 `build-pc/time_tick_preview.exe --preview-ready`：跳过引导、采用中文与虚拟校准，不代表真实设备已配置。F5仍保留完整首次引导流程。

直接打开新版天气地点页：`build-pc/time_tick_preview.exe --preview-location`。输入拼音如 `hangzhou` 搜索，或点常用城市，再确认包含省份/国家的候选。经纬度入口收在“高级”中。需要验证真实城市查询链路时可运行 `build-pc/time_tick_preview.exe --check-location-live`，仅搜索公共城市“Hangzhou, CN”，不会打印电脑IP或地区。

## 模拟控制与检查

| 控制窗口 | 预期行为 |
| --- | --- |
| 正放 / 时钟 | 显示时钟和示例天气，默认暂停倒计时 |
| 右转 / 倒置 / 左转 | 稳定后启动方向预设，并旋转屏幕和触摸坐标 |
| 朝上平放 | 不启动或重置计时，保留上一屏幕角度；已有计时继续 |
| 屏幕朝下 / 不启动 | 不启动或重置计时，保留原屏幕角度，已有计时继续推进 |
| 默认时长 / 5秒演示 | 三个定时方向切为5秒或默认值，重置当前计时；平放不计时 |
| 切换示例天气 / 无数据 | 切换示例天气与无天气 |
| 电量模拟 | 充电、正常放电、低电、满电和读取失败循环；页面明确标注模拟电量，不代表实物 |
| 下一种天气 | 依次切换晴、多云、雨、雪、雾、雷雨，温湿度、桌宠节奏和天气道具一起变化；当前行走/互动结束后衔接自主动作 |
| 时段 | 跟随时钟 → 清晨06点 → 白天12点 → 黄昏18点 → 夜晚22点；改变场景和显示时间，不改变倒计时 |
| 季节 | 跟随日期 → 春4月 → 夏7月 → 秋10月 → 冬1月；查看不同服装与氛围 |
| 当前静止 / 移动中 | 输入90°/s角速度，检查移动时不切换方向 |
| 虚拟校准已完成 / 尚未校准 | 点击清除或恢复虚拟校准；也可在设置中进行两步校准 |
| 网络扫描：正常 / 空列表 / 失败 | 切换模拟结果，再到网络页刷新 |

按钮分钟数表示初始默认值，实际时长以设置页为准。方向滤波约需0.5–0.8秒。仅设置页冻结姿态切换，已有倒计时继续运行；养成页可直接翻转进入计时。到时提醒覆盖养成和设置，结束提醒后恢复原设置表单。控制面板顶部显示校准、运动、方向和计时状态。

网络页六个 AP 是模拟列表，可检查滑动选择、带数字行的键盘和错误重试。密码 `wrongpass` 模拟失败；开放网络无需密码。不会读取电脑 Wi-Fi，也不需要真实密码。

校准检查：控制窗口选“正放”，稳定后记录正放；选“右转”，稳定后记录右转。虚拟坐标为正放+Y、右转+X、朝上平放+Z，不代表实物已校准。

## 倒计时演示

1. 完成引导，控制窗口确认“当前静止”和“虚拟校准已完成”。否则点击相应按钮恢复。
2. 点“右转 / 5分钟”，稳定约一秒后出现圆形倒计时表盘。绿色圆环和百分比随剩余时间变化；暂停后变为暖棕色，继续恢复绿色。暂停/继续不改变预设，停止后可点“开始”。
3. 点“正放”回到时钟并暂停；再点“右转”从5分钟重新开始。左转、倒置使用自己的预设；朝上平放没有计时预设，保留此前屏幕方向及已有计时状态。运行中平放不重置截止时间，回到原计时方向也不重新开始。
4. 切到“5秒演示”，再选择定时方向；归零后出现带完成勾选图标的金色“时间到 / 结束提醒”。选择另一方向并稳定后仅结束提醒，保持该方向不会重新计时，再选一个定时方向才开始新一段。正放、另一侧、平放与朝下均可结束提醒；“移动中”及不足450毫秒的短暂姿态不会误触发。演示结束切回默认时长。
5. 在正放页打开陪伴，再点“右转”，确认自动进入计时。养成不是使用计时器的前置条件。

PC窗口模拟的是显示面板像素：右转/左转时画面在固定的电脑窗口内横转，等价于实物随设备旋转后保持可读。平放保留上一角度。运动中不触发新方向，未校准不会启动翻转计时；这两种状态均明确显示在控制面板。

## 存档、模拟边界与故障排查

“设置 → 系统 → 到时提醒”可选九种铃声：清亮钟声、电子闹铃、轻快旋律、叮咚门铃、小院风铃、木琴跳音、晨光唤醒、游戏过关、节拍提醒；展开列表后上下滑动。音量0–80%、提醒时长15/30/60秒，响铃、振动和日常轻提示音分别设置。“试听 3 秒”使用未保存的当前选项；停止、返回或保存会结束试听。电脑预览仅模拟提醒状态和时序，不驱动扬声器或马达；实际响度请在设备上试听。首次引导的“声音”页现在显示为“到时提醒”。

桌宠进度保存到 `build-pc/preview_pet_save.bin`，旧三宠存档首次加载时继承经验最高伙伴，保留专注成就；其他旧槽位留存但不显示。主动照料保存成功后才播放动作和增加数值；被动变化每分钟保存，正常关闭也尝试保存。自动测试使用内存状态，不读写演示存档。**清理构建目录前先备份此文件。**

时钟使用电脑时间与设置时区；天气为明确标记的示例数据。地点定位/城市搜索通过Windows HTTPS使用电脑真实网络，设备的Wi-Fi、天气请求、IMU、声音、麦克风、振动和NVS不在PC预览中验证。IP定位可能指向代理或运营商出口，请核对后点选。系统设置不跨会话保存，Wi-Fi凭据不写入电脑存档。

| 问题 | 处理 |
| --- | --- |
| 找不到运行配置或任务 | 确认打开 `Time-Tick V1.0` 文件夹 |
| 找不到 cmake / gcc / gdb | 检查 PATH 并重启 VS Code；F5 需要 C/C++ 扩展 |
| Resolve firmware dependencies | 用官方 ESP-IDF 扩展解析本工程依赖 |
| 无法写入 exe / Permission denied | 关闭预览，再 Shift+F5 停止调试，重新构建 |
| 缺少 SDL2.dll | 重新执行“编译电脑预览”，不要单独移动 exe |
| 旋转了却没有开始计时 | 检查“校准：完成”“当前静止”；先正放再选定时方向。0秒预设会显示未启用；朝下不触发 |
| 看不到修改后的画面 | 用F5或“启动电脑预览”任务重编译，检查终端是否失败 |
| 首次编译慢 | 保留有效 `build-pc/`，不要反复清缓存 |

设备画面为480×480原生尺寸、RGB565，中文模拟控制台为480×720。真实屏幕色彩、流畅度、触摸和耗电需实机验收。最新结果见 [呆猫、电量与稳定性验证](../test-records/2026-10-21-daimao-power.md)，无窗口渲染导出方式见 [场景验证](../test-records/2026-10-20-scene-voice.md)，素材复现见 [美术说明](../assets/pets/README.md)。

欢迎页使用艺术字。计时设置先选方向，用鼠标按住“小时／分钟／秒”数字上下拖动，松开自动对齐；也可点相邻数字或常用时长。选24小时后分秒自动归零，最短1秒；独立开关用于关闭方向。切换方向会保留草稿，点保存才生效，直接返回取消修改。“正放后的处理方式”另页设置，返回滚轮页仍保留草稿。

陪伴页查看专注成就：用至少1分钟的计时自然完成后计入奖励，5秒演示不奖励。天气切换有650ms过渡。语音助手与模拟唤醒入口已从本版移除，源码和教程见[下一版本归档](../archive/voice-assistant/README.md)。
