# 呆猫动作素材

2026-10-21 使用 Codex 内置 imagegen 生成；完整提示词保存在 [prompt.txt](prompt.txt)，透明源图为 [atlas.png](atlas.png)。角色参考《怪物猎人》艾露猫外观 Kit T.（呆猫），参考页面：[Good Smile 官方产品](https://www.goodsmile.com/en/product/1140799/Nendoroid%2BPalico%2BLayered%2BArmor%2BKit%2BT.%2BVer.)。该角色标识 ©CAPCOM；这里记录的是 AI 重绘来源，不将角色声明为项目原创或已取得额外授权。未从游戏提取素材。

源图为 6 列 × 8 行，共 48 个姿态：待机、向右行走、吃饭、玩球、擦洗、睡觉、庆祝各6帧，另有雨披、围巾、扇子各2帧。左向行走镜像复用6帧，总计54个固件帧。雨披与围巾直接画入姿态，不叠加位置不准的服装贴片；换装目前用于停留状态，行走/互动使用基础服装。

运行时保留距离驱动的步态、加减速、轻微呼吸与落地起伏；待机有分时眨眼/张望/伸展，睡眠有呼吸/打哈欠，触摸回应播放6帧庆祝。天气、昼夜仍控制自主活动，明确休息及照料动作优先，移动不显示对话气泡。成长与成就保持只有正反馈。

转换命令（Python 3 + Pillow）：

```powershell
python assets/pets/daimao/convert_assets.py --proof
```

脚本只提取透明轮廓、切片、统一对齐缩放、镜像和格式转换，不重新绘制。输出104×104 RGB565+A8：保留8位透明度，54帧像素共1,752,192字节。生成代码在 `main/generated/ui_daimao.c/.h`，逐帧拼图和GIF在忽略目录 `build-assets/daimao/`。运行时无需PNG解码或联网下载。

当前只显示呆猫。旧配置中的猫/狗/小鸡选择会转为呆猫；首次加载旧养成存档时继承经验最高伙伴的状态，专注成就保持，其他旧槽位留在存档中供恢复，不加载对应美术。
