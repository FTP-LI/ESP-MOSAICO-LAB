# 全屏天气背景

正放时钟页使用完整的 480×480 场景，上方天空承载时间天气，下方草地供桌宠活动。定时方向使用独立倒计时页，背景与桌宠不参与计时画面。

## 天气与文件路径

背景地址是项目内的素材路径，由 `scenes.json` 管理；运行时不下载图片。天气数据来自 Open-Meteo，分类实现位于 `main/core/weather_model.c`，按 [官方天气代码表](https://open-meteo.com/en/docs)映射：

| 天气 | WMO 代码 | 原图 |
| --- | --- | --- |
| 晴 | 0、1 | `sunny.png` |
| 多云 | 2、3 | `cloudy.png` |
| 雨 | 51、53、55、56、57、61、63、65、66、67、80、81、82 | `rain.png` |
| 雪 | 71、73、75、77、85、86 | `snow.png` |
| 雾 | 45、48 | `fog.png` |
| 雷雨 | 95、96、97、99 | `storm.png` |
| 未识别或首次无数据 | 其他代码 | `cloudy.png` 中性回退；文字仍显示暂无天气 |

网络中断后，有效的最近观测及背景继续保留，真实数据标注“缓存”；没有观测时不虚构晴天。PC 示例数据单独标记，不显示真实数据的缓存状态。换天气只替换背景，不重置计时、桌宠位置或照料动画。养成页裁取同一张图的下方草地区域。

## 替换和编译

在 `Time-Tick V1.0` 目录使用 Python 3 / Pillow：

```powershell
python assets/weather/convert_assets.py
```

转换器读取 `scenes.json`，将六张原图居中裁切缩放为 480×480 RGB565，生成 `main/generated/ui_weather_art.c`、`ui_weather_art.h`，以及忽略目录中的 `build-assets/weather-contact.png` 检查图。六张图的像素数据共 2,764,800 字节。

替换对应 PNG（或修改 manifest 中的相对 `source` 路径），运行转换器，再按 [PC 预览说明](../../pc/README.md)增量编译。不要手改生成的 C 数组。固件与 PC 使用同一份转换结果，无需 PNG 解码器或资源服务器。

## 来源与范围

2026-10-20 使用 Codex 内置 imagegen 生成，以 `../pets/garden.png` 为构图风格参考；完整生成提示词在 `prompts.json`，六张原图保留在本目录。用户提供的产品截图用于参考布局，没有直接提取其背景、图标或代码。

当前为六种静态日间天气背景，桌宠使用逐帧动画。尚未实现昼夜/暮色自动切换、雨雪粒子、逐小时/七日天气页、自动定位或手机网页设置；参考图中的这些功能不能视为本项目已实现。

场景切换使用650ms双图层交叉淡入。当前淡入结束前收到的新天气在下次渲染切换到最新场景，避免中途跳变；隐藏场景直接更新。角色和前景控件不参与背景混合。
