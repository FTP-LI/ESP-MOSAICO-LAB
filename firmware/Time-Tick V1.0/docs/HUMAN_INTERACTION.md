# 声音与振动

当前V1.0保留计时提醒和日常声振反馈。语音助手留待下一版本，源码和原配置教程见[归档说明](../archive/voice-assistant/README.md)。

计时是首要功能。声音使用固定官方BSP的ES8311接口，振动使用 `bsp_motor_set()`，不重写引脚。设备I2S为48kHz/16bit/双声道；计时和姿态主循环每20ms运行，音频与网络分别由独立任务处理。

## 已有声振反馈

| 时机 | 声音 | 振动 |
| --- | --- | --- |
| 开始/继续 | 轻短音 | 约45ms |
| 暂停 | 较低短音 | 约45ms |
| 自然到时 | 九款铃声可选，每3秒重复一段，持续15/30/60秒 | 每3秒短振两次，可单独关闭 |
| 互动成功 | 轻短音 | 约35ms |
| 设置中试听 | 当前草稿铃声，最多3秒 | 按草稿振动开关 |

闹铃具有独立的0–80%音量（默认65%）和振动开关。日常提示音沿用原有日常音量（默认25%）。到时提醒优先，停止试听或结束提醒会取消待播内容；音频线程在10毫秒分块之间检查取消。

## 音频任务

当前音频任务只处理铃声与提示音队列，空闲时阻塞等待，不轮询语音状态。声音入队即可唤醒；PCM格式、音符表、波形余量、淡入淡出、取消检查及结束后的I2S空闲回收保持不变。没有语音网络任务、唤醒模型或麦克风采集路径。

闹铃结束操作：轻点/长按圆盘结束提醒；第一次翻转只关闭提醒，下一次翻到定时方向才开始新计时。现有屏幕亮度、翻转防抖与计时周期保持不变。
