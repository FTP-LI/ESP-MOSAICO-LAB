# 专注成就与轻陪伴

主屏右下“陪伴 / Pet care”展示完成专注、累计分钟、亲密度和成长，并提供喂食、玩耍、洗澡和休息。“专注成就 / Growth journal”查看六个阶段目标。当前只保留呆猫。旧三宠美术归档，旧存档迁移时继承经验最高伙伴的进度，专注成就不清空。

## 专注奖励

只有自然到时、预设至少60秒的计时才计入完成。5秒演示、提前停止、换方向重启不产生奖励；暂停不增加有效专注时长。每次完成按本次预设时长累计，重复刷新到时页不会重复结算。

| 成就 | 解锁条件 |
| --- | --- |
| 初见专注 | 完成一段至少1分钟的专注 |
| 扎根时刻 | 单次完成25分钟 |
| 一小时的光 | 累计完成60分钟 |
| 步履不停 | 完成10段 |
| 小院成林 | 累计完成5小时 |
| 专注旅人 | 完成50段 |

成就以卡片、进度条和到时页的短暂提示呈现，永久保留。不设连续打卡、不因间断清零、不扣分。每次完成为当前伙伴增加 `10 + min(完成分钟数, 50)` 经验及20点内部亲密度。每100点经验升一级，最高10级；亲密度最高1000，界面显示百分比。

## 纯正反馈

内部饱食、心情、精力、清洁为0–1000，用于旧存档兼容与动作状态，界面不再将它们展示为需要管理的四项负担。

| 操作 | 增益 | 间隔 |
| --- | --- | --- |
| 喂食 | 饱食+250、心情+30、亲密+15、经验+8 | 5秒 |
| 玩耍 | 心情+220、亲密+15、经验+12 | 5秒 |
| 洗澡 | 清洁+350、心情+25、亲密+15、经验+8 | 5秒 |
| 休息/起床 | 切换休息，睡眠恢复精力 | 2秒 |
| 摸头 | 心情+30、亲密+10、经验+2 | 30秒 |

数值有上限；互动不会降低其他状态，满状态仍可播放互动。互动可唤醒伙伴，不需先喂食。需求不随时间下降，旧存档低状态自动恢复；亲密和经验不衰减。没有死亡、每日任务或催促照料提示。自主散步不刷经验。

## 动作与页面

六帧步态按位移推进；进食1.8秒，玩耍/洗澡2.7秒，播放后恢复活动。期间暂时禁用重复互动，避免截断。自然散步与草地召唤不显示台词；触摸/照料反馈只在停下时短暂显示。主屏活动范围避开下方按钮。

陪伴页不冻结姿态识别：翻到定时方向立即退出，计时和到时提醒始终优先。仅设置表单暂时冻结姿态切换，已有计时照常运行。默认“正放暂停，翻到定时方向重新开始”。

## 随天气生活

主屏和陪伴页使用同一套天气行为，天气只改变表现，不扣状态、不增加维护任务，也不自行奖励成长或成就。

| 条件 | 呆猫表现 |
| --- | --- |
| 晴 | 散步、张望、伸展；轻量蝴蝶装饰 |
| 多云 | 散步和停留，轻微风线 |
| 雨/雷雨 | 停留时穿雨披，减少自主移动；仍响应草地召唤 |
| 雪/寒冷季节 | 停留时戴围巾，更常休息；雪天轻微呼气白雾 |
| 夏季 | 停留时使用扇子姿态 |
| 雾 | 慢走、小范围探索，不再显示悬空小灯 |
| 夜间 | 更多睡眠和安静停留 |
| 无有效天气 | 普通散步、休息，不假定实时天气 |

换装直接绘入完整姿态，目前用于停留状态；行走和照料使用基础蓝色服装，不再叠加错位服装贴片。自然待机有眨眼、张望和伸展，睡眠有呼吸和打哈欠。用户互动优先，喂食、玩球、洗澡完整播放后恢复自主活动。移动不显示台词气泡。

天气背景保留650ms交叉淡入、季节/昼夜氛围800ms过渡；旧伞、软垫和三宠素材已归档。轻量装饰与步态共用小院定时器，隐藏页面跳过刷新；电池供电时降低视觉刷新频率。实现见 `main/ui/ui_garden.c`、`main/ui/ui_sprite.c`、`main/ui/ui_pet_weather.c`；[呆猫素材与完整提示词](../assets/pets/daimao/README.md)。

## 保存

- 桌宠存档升级为schema 3；自动迁移schema 1/2，呆猫继承经验最高旧伙伴的状态、经验和互动次数，保留共享专注进度及成就。其余旧槽位只留作兼容，不显示、不增长。
- 实机使用 `time_tick/pet_book` NVS；PC使用exe旁 `preview_pet_save.bin`，临时文件写入后原子替换。测试不操作日常存档。
- 主动照料保存成功才提交奖励和动作，失败可重试。专注完成更新内存后立即尝试保存，失败保留待写状态，每60秒重试；突然断电可能丢失尚未写入的奖励。正常关闭PC也尝试保存。
- 设置单独升级为schema 4，迁移schema 1/2/3的网络、校准、预设和偏好，增加WGS84经纬度并清除不再使用的朝下预设；保留提示音开关与音量。

实现见 `main/core/pet_model.*`、`main/ui/ui_pet.*`、`main/platform/pet_storage.*`。素材见 [美术说明](../assets/pets/README.md)，声音与振动见 [交互说明](HUMAN_INTERACTION.md)。本地单机，无支付、账号和云同步。
