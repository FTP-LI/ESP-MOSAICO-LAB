# Time-Tick 田园界面规范

以明亮田园生活为灵感，使用原创小院、动物和天气图案，没有导入《星露谷物语》的素材。界面按设备原生 480×480 像素绘制，PC 与设备编译同一套 LVGL 源码。

## 可配置昼夜主题（2026-10-21）

“设置 → 系统 → 显示 → 主题与时段”提供日间、夜间、自动三个按钮。默认自动：20:00–次日05:00深色，其余时间日间；夜间开始/日间恢复均可用时、分滚轮调整，精确到分钟。自动模式是起始时刻包含、结束时刻不包含，跨午夜与同日区间均支持；相同时刻拒绝保存。手动模式保留时段值但禁用滚轮，不依赖有效时钟。设置实时预览，保存生效，返回恢复进入本页前的主题草稿；首次引导中的“应用”仅保留草稿，最终完成引导时才写入NVS。

夜间采用深蓝灰底、柔和浅色文字及绿色/琥珀色强调。天气与桌宠光照同步主题，不修改真实时钟、季节、倒计时或亮度；自动模式白天区间保留自然清晨/黄昏效果。使用用户设置时区，不计算日出日落。

覆盖首页按钮与电量、设置/引导、键盘、地点与网络对话框、下拉弹层、计时滚轮、成长成就及所有倒计时状态。夜间运行/暂停/到时仍分别用绿/棕/金色与文字共同区分；圆盘保留天气渐变背景，中心使用深色衬底和浅色大数字，不以降低整屏透明度实现。

`ui_theme.c` 绑定每个控件的原始颜色及部件/状态，跨时段更新颜色，控件删除时释放绑定。新建页面直接使用当前配色；不重建表单，已输入内容、光标、下拉选项和滚轮草稿保留。相同时段重复快照不重新染色；没有新增轮询任务、图像资源或帧动画。仅改变UI颜色，不改背光、显示时钟、电源管理或计时核心。桌宠与天气继续使用原有环境光过渡。

PC `--smoke-theme` 覆盖时间边界、无效时钟、实时编辑保留、页面释放、到时翻转与圆盘手势；夜间实际LVGL效果及实机记录见[验证记录](../test-records/2026-10-21-night-theme.md)。

## 倒计时优先

Time-Tick 的主体是翻转计时。正放显示时钟天气；右转、倒置、左转三个定时方向切换到独立的圆形表盘。四个竖放朝向同步旋转屏幕和触摸，平放保留之前角度，朝下不触发新计时。天气背景上叠加奶油色渐变、鼠尾草绿进度环、细刻度和两侧枝叶呼应小院；中间依次是沙漏图标、状态胶囊、大数字、方向及预设时长、剩余百分比。圆盘轻点开始/暂停/继续，长按0.8秒停止并重置；底部只显示操作提示，右上可进入设置。

通常使用 84 px 数字；剩余时长达到 100 分钟时切换为 52 px，最长 `1440:00` 完整显示。进度环按剩余时间逐渐缩短；运行使用绿色、暂停使用暖棕色、停止待启用使用灰绿色、到时使用金色及完成勾选图标。状态始终有文字，不只依赖颜色。表盘中心使用高不透明度衬底保证读数清晰（日间浅底、夜间深底），向下渐隐露出天气场景。停止后保留当前方向的计时页，可轻点圆盘重新启动；时长为 0 的方向明确显示未启用。

表盘由 `main/ui/ui_focus.c` 独立维护，PC 和 ESP-IDF 共用。枝叶、刻度、图标、圆环均为 LVGL 原生绘制，没有新增图片资源或独立动画循环；计时仍使用原来的单调时钟核心。

到时显示暖色“时间到”页面与“结束提醒”，设备请求 3 秒间歇振动，PC 仅演示视觉提醒。到时页面优先于养成和设置；结束提醒后恢复原设置表单，未保存内容仍保留。正放暂停；再翻到定时方向重新开始预设时长。设置页仍暂时冻结姿态识别以便编辑/校准；养成页不会冻结姿态。

## 正放主画面与养成

- 时钟与天气直接叠加在天空上：52 px 时钟、24 px 温度、16 px 日期；顶部轻薄渐变保证对比度。项目标题为 Time-Tick V1.0。
- 天气场景铺满 **480×480**，使用晴、多云、雨、雪、雾、雷雨六种背景，切换时两层图片650ms交叉淡入，快速切换先完成当前过渡再取最新天气；资源路径与替换方法见 [天气素材](../assets/weather/README.md)。下方草地供伙伴活动，位置不侵入文字与控件；当前活动y范围260–294，角色底部不超过398。自然散步和召唤不显示台词。
- 猫、狗、小鸡使用透明角色帧，包含站立、开心、睡眠及六帧行走、进食、扑球、洗澡和镜像行走。自主散步、停留、开心、打盹，点地面可召唤，点角色可摸头。低精力自动休息；活动位置限制在草地范围内。
- 画面去掉厚木框，改用奶油色背景、细边框、圆角和轻柔的绿色控件。动画按页面可见性更新，移动和动画状态每50 ms更新；步态按实际移动距离推进，每48 px完成六帧。天气决定活动节奏，晴天70–80 px/s，多云52、雨42、雪38、雾32、雷雨手动召唤36；无天气64 px/s。进食每帧150 ms，共1.8秒；玩球/洗澡共2.7秒。照料期间停止行走，完整播放后恢复自主活动。
- 天气同时影响伙伴：晴天蝴蝶、多云轻风、雨天小伞、雪天软垫与呼吸白雾、雾天缓缓漂移的雾带（移除小灯）、雷雨伞下休息。132×130装饰层在角色身后、650ms切换，范围不侵入底部按钮；小伞固定落地，其他轻装饰跟随角色。喂食/玩耍/洗澡时隐藏天气道具；天气不影响成长数值，不增加提示台词或维护负担。
- 正放页取消四按钮底栏。设置位于右上，陪伴是草地右下的小入口；当前V1.0语音助手已归档，无对话入口，计时通过圆盘手势控制。数据来源缩短为 Open-Meteo，PC 明确标记示例天气。
- 陪伴页有 448×190 场景、专注次数、累计分钟、亲密度、成长条、可选互动和六项专注成就。需求不随时间下降，低状态自行恢复，没有催促照料提示。翻转立即退出养成并启动计时；专注期间隐藏伙伴和主页控件，保留天气场景与粒子。完整规则见 [养成说明](PET_CARE.md)。
- 照料完成必须等存储成功后显示反馈；失败不会增加数值或消耗冷却时间。猫、狗、小鸡各自保存。成就按完成专注解锁，保留进度，不设连续打卡惩罚。

## 网络与首次设置

首次启动以手绘Time-Tick艺术字作为唯一主标题；顶部居中显示16px浅色“版本 V1.0 / Version V1.0”。语言页不显示三只伙伴，依次为“语言 → 网络 → 伙伴 → 显示 → 声音 → 天气 → 方向校准”七页，也可离线进入。伙伴图片与名字都可点选，选中后播放六帧玩球动作约2.7秒，其他伙伴保持站立。显示/声音/天气不再挤在伙伴页下方；中英文主要选项在480×480内直接可见。保存成功后才退出，失败可重试；实机使用NVS记录已完成引导。

日常系统设置有伙伴、显示、声音、天气四个分类按钮；分类页返回保留草稿，退出系统页撤销未保存更改。天气页可启用WGS84经纬度定位，有边界与输入校验，显示Open-Meteo网格预报及刷新间隔。中文模拟控制台独立于产品语言，明确显示虚拟姿态、当前计时和模拟天气。

网络交互参考官方 Vibe 的 `vibe_ui.c` 与 `factory_network.c`：进入页面自动扫描，按信号强度显示去重后的网络列表，可触摸上下滑动；网络行显示 SSID、加密状态和信号。点选后进入独立密码页，不需要手填普通 SSID。

密码键盘常驻数字行，支持大小写、符号、空格、退格、光标移动与确认。默认隐藏密码，可勾选显示；开放网络无需密码。“其他网络”保留隐藏 SSID 的手动入口。连接失败保留输入供修改，取消连接表单恢复进入前的连接配置；刷新可重试扫描。原有设置页返回仍撤销未保存的网络变更。

Wi-Fi 驱动在独立任务中处理异步扫描/连接，HTTPS 天气请求使用另一任务，避免天气请求阻塞配网。扫描最多展示 24 个结果；实际设备的连接、断线和超时行为仍需实测。PC 列表明确标为预览数据，不读取电脑真实 Wi-Fi。

## 语言与字体

产品页面及交互提示支持简体中文/English。字体使用 Noto Sans CJK SC 的 4 bpp 数据，18/24 px 用于正文/标题，16 px 字体含 GB2312 常用汉字以显示多数中文网络名；不代表完整 Unicode 字体或中文输入法。城市和隐藏网络手动输入仍使用字母/数字键盘。

字体版权与生成方式见 [字体说明](../assets/fonts/README.md)。最新验证见 [倒计时表盘验证](../test-records/2026-10-20-companion-interaction.md)，启动方式见 [电脑预览](../pc/README.md)。

计时设置使用方向选项、独立启用开关、分钟/秒输入与常用时长快捷键，拒绝秒数超过59及总时长超过24小时。声音与振动见 [交互说明](HUMAN_INTERACTION.md)。

## 季节、昼夜和待机（2026-10-20）

- 春季花叶领巾、夏季草帽、秋季围巾、冬季毛线帽；雨/雷雨优先雨披，夜晚优先睡帽。秋季围巾使用与三宠待机/步态一体绘制的动作帧，毛发、耳朵和前爪遮挡正确，伸展中仍保留围巾；不再把一张正面围巾贴到腹部或侧身。其他独立配饰在进食、扑球、洗澡、睡眠和伸展时隐藏；睡眠保留呼吸起伏。
- 待机有六张原创透明帧：睁眼、半眨眼、闭眼、张望、伸展、恢复。走路按距离迈步，新增加速/减速与轻微抬步；不会直接匀速滑走。所有装饰只改变表现，不扣成长值。
- 天气粒子每50ms绘制，隐藏页面不刷新：雨滴/涟漪、飘雪、漂移雾、微风、花瓣/秋叶；雷雨仅偶尔柔和闪光。夜间星光和月牙，伙伴减少活动；移除夜间太阳与蝴蝶。
- 固定本地时段：05–07清晨、08–16白天、17–19黄昏、20–04夜晚。月份决定季节，明确经纬度为南半球时季节反转；未定位时默认北半球。不是日出日落计算。
- 正放暂停时用24px深色数字和浅色卡片显示剩余时间。成就改为“专注足迹”卡片，标题、目标和进度条分离，永久保留、不设打卡压力。
