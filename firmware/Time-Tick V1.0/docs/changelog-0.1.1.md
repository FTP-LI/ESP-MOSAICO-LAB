# Time-Tick 0.1.1 开发预览

- 迁移至官方 Vibe Mode 0.2 产品契约、Iris wire 2 和 Recovery ABI 2。
- 使用独立的 USB 控制与数据通道；重新构建应用和系统更新包。
- 修复从 Vibe Mode 0.2.1 启动应用时因新旧 SDK 时钟门控约定不同导致的 Wi-Fi 初始化卡死；在时钟树启动阶段恢复 REF160M 门控，保留原有动态调频策略。
- 保留翻转计时、圆盘手势、九种铃声、天气、呆猫及昼夜主题的现有交互。
- 修复设置页屏幕锁定：四个竖放方向均可旋转，保留未保存表单；编辑期间翻转不会启动或切换计时，平放保留原角度。
- 新增六张中文介绍图、使用指南和中英文设备目录介绍。

旧版 Vibe Mode 设备需要先通过官方 ROM 恢复流程迁移基础固件，不能直接跨代 OTA。此版为开发预览，长期续航、电量准确性和异常断电问题仍需继续验证；AI 语音助手不在本版范围内。
