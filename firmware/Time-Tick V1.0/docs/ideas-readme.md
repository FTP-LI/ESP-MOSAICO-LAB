# Time-Tick V1.0（开发中）

面向 ESP-Mosaico CoreBoard V1.2 的翻转计时器，应用版本 0.1.0。正放显示时钟、天气和呆猫；翻转启动预设倒计时，到时播放可选铃声并振动。

右转、倒置、左转默认分别为 5、10、25 分钟。设置中通过分钟和秒滚轮调整，最长 24 小时，各方向可单独关闭。四个竖放方向同步旋转屏幕和触摸；朝上平放保留上一屏幕方向，不再提供平放计时预设，朝下也不启动新计时。正放暂停；计时圆盘轻点开始、暂停或继续，长按 0.8 秒停止并恢复预设时长。响铃后第一次翻转只关闭提醒，再次翻到计时方向才开始新一段。

首次使用依次设置语言、网络、伙伴、显示、声音、天气和方向，支持简体中文与 English。方向校准需分别静止记录正放及顺时针右转 90°。显示设置支持大滑块实时预览亮度，并可选择日间、夜间或自动主题；自动模式可设夜间开始与日间恢复时刻，默认 20:00–次日 05:00，按设备所选时区运行。返回取消当前编辑，保存后记忆。计时圆盘、设置、键盘、列表及呆猫受光随主题变化。

天气地点可通过联网估计后确认，或搜索城市并从候选列表选择；高级设置可填写 WGS84 经纬度。内置 [Open-Meteo](https://open-meteo.com/en/docs) 接口无需在设备填写天气密钥，城市数据来自 [GeoNames / Open-Meteo Geocoding](https://open-meteo.com/en/docs/geocoding-api)。天气是模型网格数据，非小区级实测。SNTP 联网校时，断网保留天气缓存提示并继续计时；断电后需重新校时，运行中的计时不跨重启保存。

当前固件只包含呆猫，天气、时段和互动影响其活动，完成专注逐步解锁永久成就，不需要每日照料。旧伙伴与语音助手已分别归档，当前版本不含语音聊天、麦克风采集或唤醒服务；下一版本再接入语音助手。

**2026-10-21 验证状态：17 项核心及 PC 界面回归通过，ESP-IDF 应用镜像为 8,054,784 字节，官方 `.irisfw` 系统更新包构建与布局校验通过。此前实机翻转、圆盘手势、亮度与提醒音已有用户确认，最新主题配置的安装记录见项目测试文档。长期续航和异常断电仍需持续验证，尚未在 Mosaico Ideas 发布。** 电脑预览中硬件状态与示例天气有模拟标记，不能替代实机测量。
