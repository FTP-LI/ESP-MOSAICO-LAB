# Time-Tick 0.1.1 使用指南

对应 Time-Tick V1.0 系列开发预览版，设备为 ESP-Mosaico CoreBoard V1.2 / ESP32-S31。

## 安装前准备

此包适配 Vibe Mode 0.2 / Recovery ABI 2，已在官方 Vibe Mode 0.2.1 上验证。旧版基础固件需要先按官方迁移流程升级，再安装 Time-Tick 0.1.1；不要将旧版应用包与新版安装流程混用。已有同布局设备通过系统更新安装，保留用户设置。

## 首次启动

依次完成语言、网络、伙伴、显示、声音、天气、方向七页引导。Wi-Fi 密码直接在设备上填写；当前只有呆猫一个伙伴。联网后设备自动校时；未联网时可先体验示例天气。

方向校准：将设备正放并保持静止，记录正放；顺时针旋转 90°，静止后记录右转。如果屏幕旋转方向相反，可在校准页反转旋转方向。

## 计时

| 操作 | 效果 |
| --- | --- |
| 右转 / 倒置 / 左转 | 默认启动 5 / 10 / 25 分钟计时 |
| 正放 | 默认暂停并回到天气时钟；可修改处理方式 |
| 计时中轻点圆盘 | 暂停 |
| 暂停后轻点圆盘 | 继续 |
| 长按圆盘 0.8 秒 | 停止，恢复完整预设时长 |
| 停止后轻点圆盘 | 重新开始 |
| 到时后第一次翻转 | 关闭提醒，不开始下一段 |
| 再次翻到计时方向 | 开始新的计时 |
| 平放 | 保留放平前屏幕角度，不启动新的计时 |

修改时长：设置 → 计时 → 选择方向 → 滑动小时 / 分钟 / 秒 → 保存。可使用 5 / 15 / 25 / 60 分钟快捷预设，最长 24 小时。取消「启用这个方向」即可关闭该方向计时。

## 到时提醒

设置 → 系统 → 到时提醒。响铃与振动独立开关；9 种铃声包括清亮钟声、电子闹铃、轻快旋律、叮咚门铃、小院风铃、木琴跳音、晨光唤醒、游戏过关、节拍提醒。

音量为 0–80%，可先试听 3 秒；提醒持续 15 / 30 / 60 秒，期间翻转或点击可关闭。音量建议先从中等开始调节，以实物听感为准。

## 显示与主题

设置页也会跟随四个竖放方向旋转，输入中的内容不会丢失。编辑时翻转只调整显示方向，不启动或切换计时；已运行的倒计时继续，到时仍会提醒。平放保留之前的屏幕角度。

设置 → 系统 → 显示：拖动加大的滑块即时预览亮度，保存才持久生效，返回会取消当前编辑。

设置 → 系统 → 主题与时段：可固定日间、固定夜间或自动。自动模式默认夜间 20:00–次日 05:00，两个时刻可独立调整到分钟，使用设备设置中的时区。主题切换覆盖首页、圆盘、设置、列表、键盘以及呆猫受光。

## 天气地点

在天气地点页选择：

1. 联网估计当前地区：按公网 IP 获得城市级估计，核对后确认；VPN、运营商出口可能使结果偏离所在地。
2. 搜索城市：输入城市名，从带行政区的候选列表中选择。
3. 常用城市：直接选择。
4. 高级坐标：使用 WGS84 纬度、经度，并给地点起一个名称。

天气使用 Open-Meteo 公共非商业接口；城市数据来自 Open-Meteo Geocoding / GeoNames；网络定位使用 ipwho.is。无需个人天气 Key。天气为模型网格数据，不是小区实测；断网会使用带状态标记的缓存。

## 专注与呆猫

自然完成至少 1 分钟的倒计时可记录专注，成就随完成次数和累计时间解锁。已获成就永久保留，不设置连续打卡惩罚，不需要每天喂养或维护。天气与时段会影响呆猫表现。

## 已知限制与反馈

- 这是 0.1.1 开发预览；长期续航、电量准确性与异常断电仍需进一步验证。
- 断电后需要联网重新校时，未完成的倒计时不跨重启恢复。
- 当前版本不包含 AI 语音助手、语音唤醒或麦克风采集。
- 宣传截图为共享 UI 电脑渲染，其中的天气、电量、日期为模拟数据。

反馈时请附固件版本、供电方式、操作步骤及可复现现象；请勿公开 Wi-Fi 密码、令牌或其他敏感配置。
