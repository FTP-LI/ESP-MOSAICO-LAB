# 声音、振动与通义千问语音

首次使用请先阅读 [AI对话前置准备与配置教程](AI_SETUP.md)，本文保留实现说明。

计时是首要功能。声音使用固定官方BSP的ES8311接口，振动使用 `bsp_motor_set()`，不重写引脚。设备I2S为48kHz/16bit/双声道；计时和姿态主循环每20ms运行，音频与网络分别由独立任务处理。

## 已有声振反馈

| 时机 | 声音 | 振动 |
| --- | --- | --- |
| 开始/继续 | 轻短音 | 约45ms |
| 暂停 | 较低短音 | 约45ms |
| 自然到时 | 九款铃声可选，每3秒重复一段，持续15/30/60秒 | 每3秒短振两次，可单独关闭 |
| 互动成功 | 轻短音 | 约35ms |
| 设置中试听 | 当前草稿铃声，最多3秒 | 按草稿振动开关 |
| 本地唤醒成功 | 短音后录音 | 无 |

闹铃具有独立的0–80%音量（默认65%）和振动开关。日常提示音及语音沿用原有日常音量（默认25%），当前设置页的铃声音量滑块不调整语音。提示音与计时提醒有优先权；翻入计时方向中止录音/等待/播放，清除待播内容。

## 手机配置

1. 完成设备联网，保持正放。点左下“语音助手 → 手机配置”。
2. 同一Wi-Fi下在手机打开设备显示的 `http://设备IP:8080`，输入设备屏幕的六位验证码。页面10分钟后失效；错误验证码累计10次后需重新打开。当前使用网址，不生成二维码。
3. 选择百炼地域（北京/新加坡），填写该地域的 **Workspace ID、API Key、音色ID**。新配置默认音色 `Tina`（保留既有音色配置），固定模型 `qwen3.8-omni-flash-realtime`。账号需要该模型权限；密钥与空间须匹配。服务网址由地域和空间生成，不接受任意地址。
4. 勾选启用语音助手；需要语音唤醒时勾选“本地唤醒：你好小智”。保存后点“测试连接”，在设备屏幕查看结果。测试完成真实TLS握手及session.updated，不上传录音。
5. 配置失败可重新填写；保存成功后密钥不会回显，留空会保留原密钥。“清除语音密钥与配置”同时关闭助手和唤醒。

配置页通过局域网HTTP传输，只在可信Wi-Fi中使用；API Key保存在独立 `tt_voice` NVS命名空间，当前未启用NVS加密。项目不内置共享密钥，不在日志中输出密钥或服务原始事件。连接官方服务使用WSS与系统证书包校验。费用由用户的百炼账号承担。

## 对话与唤醒

- 默认不监听。只有配置有效、助手/唤醒开关打开、设备正放或屏幕朝上平放、且不处于设置页/到时状态时，才用官方ESP-SR模型**在本地**检测“你好小智”。待唤醒音频不会上传；目前不能自定义唤醒词。
- 也可在语音页点“开始对话”。录制最长8秒；检测到讲话后停顿约0.9秒自动提交。无讲话不发请求。设备显示倾听/连接/思考/回答状态以及回复文字，文字过长可在回复框内上下滑动。
- 以16kHz单声道PCM发送给通义千问，收到24kHz单声道回复后经ES8311播放。首版为**半双工**，先说完再听回答，暂不支持边播边打断；每次唤醒是一轮独立问答，没有跨轮记忆。
- 点击结束/返回、翻入计时方向或到时会取消当前会话；已经发出的网络数据无法撤回，但迟到回复不再播放。天气与翻转计时独立运行，模型输出不能修改计时或执行设备命令。
- 最大请求录音256KB、回复PCM约1.92MB、单个服务事件64KB。连接15秒、配置8秒、回复30秒有界等待；超限/断网/认证失败显示错误，不自动无限重试。
- 唤醒模型 `wn9s_nihaoxiaozhi` 随应用嵌入，官方打包脚本生成约126KB模型包，不增加模型分区，不改动受保护Vibe区域。模型遵守 [ESPRESSIF MIT许可](LICENSE.esp-sr)。

实现入口：`main/core/voice_model.c` 做配置校验和固定服务地址；`main/platform/voice.c` 包含NVS、局域网配置页、WakeNet、会话与取消；`interaction.c` 是codec的唯一所有者；`voice_portal.html` 是手机表单。

## 电脑预览与验证边界

PC完全不使用真实麦克风和密钥。点中文控制台“模拟语音唤醒与回复”会演示倾听→思考→回答；点语音页“手机配置”仅设置本次预览的模拟已配置状态。文字明确标注模拟，不代表真实云端连接成功。

当前设备代码已通过官方ESP-IDF编译，PC自动回归验证状态与翻转优先级。**真实账号认证、收音、唤醒率、回复音量、网络延迟和功耗尚未实测**，需要连接设备并在本机配置密钥后验收。建议依次检查：测试连接、手动对话、唤醒词、取消/翻转、断网、错误密钥、重启恢复配置、到时抢占音频。不要用模拟状态替代这些检查。

官方协议依据（2026-10-20核对）：[通义千问实时语音](https://help.aliyun.com/zh/model-studio/realtime)、[客户端事件](https://help.aliyun.com/en/model-studio/client-events)、[ESP-SR](https://github.com/espressif/esp-sr)、[ESP WebSocket Client](https://components.espressif.com/components/espressif/esp_websocket_client/versions/1.7.0/readme)。
