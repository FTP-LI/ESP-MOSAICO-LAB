# Time-Tick V1.0：AI 对话准备与配置教程

核对日期：2026-10-21。适用于本工程的 ESP-Mosaico 实物固件。

按“开通百炼 → 准备三个字段 → 手机配置 → 测试连接 → 点击对话 → 开启唤醒”的顺序操作。**不需要自己部署服务器，不需要在电脑安装 Python，也不需要把密钥发给开发者。**

当前接入的是阿里云百炼 `qwen3.8-omni-flash-realtime`。固件已经实现配置、收音、请求、回复播放和本地唤醒；**尚未使用你的真实账号完成端到端验收**。“保存成功”仅表示设备保存了配置，最终应以设备能回答并发声为准。

## 1. 先准备这些东西

| 准备项 | 要求 |
| --- | --- |
| 设备 | 安装当前 Time-Tick 固件，首次配置建议接 USB，保持正放 |
| 网络 | 设备已连接可上网的 Wi-Fi，时间已联网校准 |
| 手机或电脑 | 与设备处于可互通的同一局域网；访客 Wi-Fi、AP 隔离可能阻断访问 |
| 阿里云账号 | 已开通百炼；按控制台要求完成实名认证 |
| 地域 | 本工程支持北京、新加坡，先选定一个 |
| Workspace ID | 所选地域的业务空间 ID |
| API Key | 在同一地域、同一业务空间下创建，具有目标模型调用权限 |

手机和电脑只用于填写配置。之后设备自己连接百炼，手机不需要一直打开。聊天消费由你的百炼账号承担，模型是否有可用额度、费用与限流以控制台显示为准。建议先做几轮短问答，再查看用量。

## 2. 开通百炼，找到正确的字段

### 2.1 登录与开通

1. 打开[阿里云百炼控制台](https://bailian.console.aliyun.com/)。
2. 使用自己的阿里云账号登录。首次进入按提示开通模型服务；若提示未实名认证，先完成认证。
3. 选择地域。中国大陆设备可先使用**华北2（北京）**；已有新加坡空间和密钥的用户则选新加坡。后续所有字段保持同一地域。

账号开通步骤以[官方首次调用教程](https://help.aliyun.com/zh/model-studio/first-api-call-to-qwen)为准。这里只配置设备，不需要执行该文档里的命令行示例。

### 2.2 获取 Workspace ID

1. 在控制台进入“业务空间管理”。北京入口可使用[业务空间管理页面](https://bailian.console.aliyun.com/cn-beijing/settings/workspace)。
2. 选中准备给这台设备使用的空间，复制它的 **ID / Workspace ID**。
3. 同时记下地域和空间名称，便于之后核对；设备表单填写的是 **ID**。

不要填写空间显示名称、阿里云账号 UID、应用 App ID、模型名称或完整网址。ID 原样复制，不加引号、空格或花括号。本工程根据它生成服务网址，无需手工拼接。

### 2.3 创建 API Key

1. 打开控制台的[API Key 页面](https://bailian.console.aliyun.com/model/settings/api-key)。
2. 确认当前地域和归属业务空间与上一步相同，再创建一把给 Time-Tick 使用的 API Key。
3. 若使用自定义模型权限，确保允许 `qwen3.8-omni-flash-realtime`。若由组织管理员管理账号，请让管理员检查该空间和密钥的权限。
4. 将密钥保存在你自己的密码管理器或其他私密位置，稍后粘贴到设备配置页。

这里需要的是**百炼 API Key**，不是阿里云 AccessKey ID/Secret，也不是网页聊天账号密码。不要放进 Git、README、截图、串口命令或聊天消息。设备不需要创建百炼智能体应用。

### 2.4 确认模型与音色

模型在当前固件中固定为 `qwen3.8-omni-flash-realtime`，网页没有切换模型的输入框。它使用与业务空间绑定的 WebSocket 地址，北京和新加坡不能混用密钥。[官方接入说明](https://help.aliyun.com/zh/model-studio/realtime)

首次使用推荐 **Tina**，保留大小写。也可选择 Serena、Ryan、Cindy；音色含义和可试听样例见[官方音色列表](https://help.aliyun.com/zh/model-studio/omni-voice-list)。官方 Manual 模式示例也使用 `longanlingxin`，已有该配置不会被升级强制替换。本轮将新表单的默认值统一为 Tina，不代表旧音色已经失效。

当前表单只接受字母、数字和短横线。官方列表中带空格、重音字符的音色 ID 尚不适用于此输入框，不要自行删掉空格后尝试。

## 3. 打开设备的配置网页

1. 在设备“设置 → 网络”连接 Wi-Fi，确认已连接，并返回正放首页。
2. 点击首页左下 **“语音助手”**。
3. 点击 **“手机配置”**。设备会显示一个网址和一个六位验证码。
4. 手机或电脑打开设备上显示的完整网址，例如 `http://192.168.1.123:8080`。此地址只是格式示例，必须以你的屏幕为准。
5. 填入屏幕上的六位验证码；开头的 0 也要保留。

**不要填写 `127.0.0.1:8443`。** 那是电脑上的 Iris 调试网关，不是设备的 AI 配置页；手机中的 127.0.0.1 指向手机本身。

配置窗口有效期为10分钟；每次重新点“手机配置”都会生成新的验证码。验证码累计输错10次后，回设备重新打开。设备断电、重新联网或换路由器后，IP 地址可能变化。

## 4. 逐项填写

| 页面字段 | 该填什么 | 第一次建议 |
| --- | --- | --- |
| 六位验证码 | 设备屏幕正在显示的验证码 | 原样填写 |
| 百炼地域 | 创建空间和密钥时选的地域 | 与账号实际配置一致 |
| Workspace ID | 控制台业务空间的 ID | 复制粘贴，避免手打 |
| API Key | 该地域/空间下的百炼 API Key | 首次必须填 |
| 音色 ID | 官方支持的音色参数 | Tina |
| 启用语音助手 | 是否允许点击对话及唤醒 | 勾选 |
| 本地唤醒 | 是否持续在本地检测“你好小智” | 暂时不勾选 |

点 **“保存到设备”**，等页面提示保存成功，再点 **“测试连接（不发送语音）”**。

“测试连接”检查的是设备已经保存的配置。改了输入框但没有保存就测试，会继续使用旧配置。测试不是在手机上进行，也不会使用手机麦克风。

### 如何判断连接成功

查看设备屏幕，应从连接验证提示变成 **“服务连接成功，可以开始对话”**。网页上的“已开始测试”只表示请求已投递，不代表服务已经通过验证。

这一步验证 TLS、账号鉴权和会话配置，不上传录音；仍需下一步验证麦克风与语音回复。网络或配置失败时按后文排查，不要反复重新创建密钥。

## 5. 第一次实际对话

1. 设备保持正放，留在“语音助手”页面。
2. 点击 **“开始对话”**。
3. 看到“请说话”后，在安静环境中、距设备约20～40厘米说一句短话，例如“给我一个十分钟专注的小建议”。
4. 说完停顿约一秒，设备会结束收音并请求模型。单次录音最多8秒。
5. 等待连接、思考、回答状态，确认屏幕出现文字，并能听到扬声器回复。
6. 点击 **“结束对话”** 可中止本轮。翻入计时方向也会优先回到计时。

当前采用“说完一句 → 云端生成 → 播放回答”的半双工方式，等待回答时稍有延迟属于当前流程；不要同时对着正在说话的设备提问。设备当前会先收齐本轮音频回复再播放，并非边收到边播。

语音播放沿用设备已存的日常声音音量，默认25%，**不会使用闹钟的增强增益或“铃声音量”滑块**。当前网页没有独立语音音量项；如果已有文字但回答偏小，请反馈这一现象，不要把调闹铃音量当作语音音量调节。

## 6. 点击对话正常后，再启用唤醒

1. 重新打开“手机配置”，取得最新验证码。
2. 填回相同的地域、Workspace ID 和音色；API Key 留空可以保留设备已存密钥。
3. 勾选“启用语音助手”和“本地唤醒：你好小智”，保存。
4. 退出设置，保持正放首页，清楚说 **“你好小智”**。
5. 等短提示音结束、屏幕进入倾听状态，再说问题。不要把唤醒词和整句问题紧贴在一起说。
6. 回答播放完后，等待约1.5秒，再次说唤醒词开始下一轮。

唤醒在设备本地运行，不需要手机在旁边。当前允许正放或屏幕朝上平放时工作；设置页面、侧向计时和到时提醒期间会让位给主功能。屏幕朝上平放保留原屏幕方向，不会启动新的平放计时。

固定唤醒词暂时不能改成“呆猫”等自定义名字。每次是独立的一轮问答，没有跨轮记忆、免唤醒追问、说话打断、语音设置定时器或模型调用设备工具的功能。问“帮我设五分钟”不会真的修改计时。

**发热或续航优先时，可以只启用助手、关闭本地唤醒。** 点击“开始对话”仍可使用；持续唤醒需要一直采集音频并运行识别，比点击对话有额外负载。

## 7. 修改、迁移和清除

- 保存成功后 API Key 输入框会清空，设备不回显密钥；这不代表密钥丢失。
- 当前重新打开页面不会自动回填旧地域、空间、音色和开关。修改时要重新核对这些字段；只有 API Key 支持留空保留。
- 改地域或 Workspace ID 时，一并换成相匹配的 API Key。
- 关闭唤醒：保留启用助手，取消本地唤醒后保存。
- 完全关闭：取消启用助手后保存。需要重新开通时不用重新烧录。
- “清除语音密钥与配置”会删除设备语音配置，并关闭助手/唤醒；计时预设与 Wi-Fi 不受影响。若设备转交别人，还应在百炼控制台撤销这把 Key。

## 8. 按现象排查

| 现象 | 先检查 |
| --- | --- |
| 点击手机配置提示先连 Wi-Fi | 先完成设备联网，等待分配 IP，再点一次 |
| 手机打不开网页 | 地址是否来自设备、是否带 http 和 :8080；同一局域网是否允许设备互访；访客网络/AP隔离/手机VPN是否影响 |
| 提示验证码错误或过期 | 回到设备重新打开配置，使用新的六位验证码 |
| 提示配置无效 | 空间填的是 ID 而非名称；首次 Key 非空；音色大小写及允许字符；字段没有多余空格 |
| 点击测试提示先保存、正放或结束对话 | 先保存表单，设备正放，关闭当前对话和提醒，再测试 |
| 已保存，但连接失败 | 检查地域、空间、Key 是否匹配，Key是否失效或受模型范围限制，模型权限/账号用量限制，以及设备时间和外网访问 |
| 测试成功，但“没有听清” | 先点击对话测试，看到倾听后再讲话；靠近一些、减少背景噪声；不要只说唤醒词 |
| 一直停在思考后报错 | 检查网络；说一句更短的话；查看账号调用记录是否成功或限流 |
| 有文字但没有声音 | 先试听闹铃确认硬件扬声器可用；确认回复未被翻转取消；记录文字、状态和时间，进一步排查语音输出路径 |
| 点击能对话，唤醒不灵 | 确认唤醒开关已保存、当前姿态允许；先只说唤醒词，等待提示音；若显示模型不可用，先用点击对话 |
| 回答没有记住上一句 | 当前每轮独立，属于现有功能边界 |
| 电脑预览回答正常，实物不正常 | 电脑预览是模拟状态，不连接真实百炼、不使用麦克风，不能用它证明账号或收音已经成功 |

排错时可以记录屏幕提示、操作步骤、发生时间、地域和音色。**不要发送完整 API Key。** 固件当前将网络/鉴权/模型失败合并成通用提示，不能只凭一条提示判断一定是密码错误。

## 9. 数据与验收

配置页使用局域网 HTTP，密钥保存在设备 NVS，当前没有 NVS 加密；请在自己信任的局域网配置。待唤醒音频只在本地处理；唤醒或点击开始后，本轮录音才会发往百炼。设备到服务使用校验证书的 WSS。按结束只能取消后续处理，不能撤回已经上传的音频。

首次配置完成后建议依次确认：连接测试成功、点击录音有回复文字、有声音、连续三轮独立问答、本地唤醒、翻转能中断、闹钟能抢占、重启后配置保留。云端链路需要你在本地填入真实配置后才能验收，目前没有把模拟结果当作实测结果。
