## 语音助手

语音助手已从V1.0运行时及构建移除，计划下一版本恢复。源码ZIP、校验清单、原教程与恢复步骤见[语音助手归档说明](voice-assistant/README.md)。

## 历史桌宠

`pets-2026-10-21.zip` 保存替换前的猫/狗/小鸡源图、提示词、转换脚本、服装/天气资源、旧生成C文件及原 `ui_sprite.c`、`pet_animation.c` 快照。

`pets-2026-10-21-manifest.json` 记录32个已从活动目录移除文件的原路径、ZIP条目、SHA-256和大小。删除前已逐字节哈希核对并检查ZIP完整性。归档只存于开发仓库，不在 `main/sources.cmake` 中，不进入固件。

恢复时先解压到独立目录，再按清单映射回对应路径；ZIP中的 `pets/` 对应原 `assets/pets/`，根目录旧生成文件对应 `main/generated/`。不要直接覆盖当前工程。代码快照仅供对照，重新启用旧资源需要显式修改构建清单和单宠界面。
