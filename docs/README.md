# 文档索引

本目录保存跨项目说明与通用模板。仅服务单个项目的使用说明、接线资料和测试记录放在该项目目录，通过链接关联，避免维护多份内容。

## 入口

- [仓库首页与项目索引](../README.md)
- [仓库规范](../REPOSITORY_GUIDELINES.md)
- [兼容性索引](compatibility.md)
- [发布变更记录](../CHANGELOG.md)

## 模板

| 模板 | 使用方式 |
| --- | --- |
| [项目 README](templates/project-readme.md) | 复制到实际项目目录并命名为 `README.md`，补充用途、状态、使用方法和许可范围 |
| [测试记录](templates/test-record.md) | 复制到项目的 `tests/` 或 `docs/`，记录实际执行环境和结果 |
| [硬件检查记录](templates/hardware-review.md) | 复制到对应硬件修订版，分别记录设计检查、打样和实物验证 |
| [发布说明](templates/release-notes.md) | 发布时填写项目范围、版本、验证记录、附件与升级说明 |

模板属于待填写的文档，不代表任何项目已经实现或通过验证。使用时替换占位说明；不适用的项写明原因，没有依据的参数标为“待确认”，没有执行的检查标为“未执行”。

新增项目后，同时更新根目录项目索引及本目录的兼容性索引。引用外部资料时记录版本或查询日期。
