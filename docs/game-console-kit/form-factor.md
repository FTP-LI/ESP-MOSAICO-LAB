# GamePlay 纵向与横向掌机方案

2026-10-19（Asia/Shanghai），状态 `experimental`。用户已确认：两种形态都规划，先做纵向掌机，保留横向方案；主要游戏按键使用经典手柄式硅胶导电胶，目标是柔和、安静的手感。本文落实设计方向，不是尺寸图、采购单或制造文件；尚未完成实物测量和样件手感验证。

母 PCB 继续使用原工程中的 **GamePlay V1.0**，不建立 EDA 副本。当前母版仍为九键电气验证原理图和空 PCB；这次只更新设计说明，没有将现有轻触开关封装冒充硅胶触点封装。

## 两种形态的共同部分

复用主机的屏幕、电池、音频和振动马达，沿用 [H2 九路 GPIO 定义](../../hardware/gamepad-board/rev-0.1/interfaces.md)。纵向／横向指整机控制区的位置，不要求旋转方形屏幕，也不改变逻辑键码。

| 项目 | 纵向：先实现 | 横向：保留设计 |
| --- | --- | --- |
| 正面关系 | 主机在上，控制区在下 | 主机居中，方向键在左，A/B 在右 |
| 主操作 | 左侧一体十字键，右侧 A/B；A 在右上、B 在左下 | 同一左右手分工，扩大两手间距；具体距离由纸样决定 |
| 辅助键 | Select/Start 在控制区下部；Menu 靠近屏幕下缘并避开动作键 | Select/Start 在屏幕下方；Menu 位于不易误触的位置 |
| 结构支承 | 主机托架与下部控制板共同固定在壳体；插针不承担握持弯矩 | 中央主机托架连接两侧握持区；跨越主机的连接件需要支承 |
| 电气连接方向 | 左 H2 引出后沿壳内左侧向下接控制区 | 同样从左 H2 取得九路输入，右侧按键经壳内布线返回左侧 |
| 当前交付 | 本方案、结构测量表、下一轮胶垫样件与按键纸样验证 | 本方案及下图；尚无独立 PCB/CAD，不复制整套工程 |

以下仅表示功能相对位置，**非比例图，不可用来确定孔位或板框**。

```text
纵向主方案                         横向保留方案
┌───────────────────┐       ┌────────────────────────────────┐
│     主机屏幕      │       │    ↑     ┌──────────┐      A   │
│                   │       │  ←   →   │ 主机屏幕 │    B     │
│       Menu        │       │    ↓     └──────────┘          │
│    ↑          A   │       │          Select Start  Menu    │
│  ←   →      B     │       └────────────────────────────────┘
│    ↓              │

└───────────────────┘
```

## 弯排针和内部连接

优先验证 **2×10、2.54 mm、90° 公排针** 从左 H2 水平插入的结构。官方整机照片中的接口呈插孔外观，因此扩展侧以公针为候选方向；仍须用持有设备确认公母、Pin1、插接面、插入深度和高度。商品写着“2×10 弯排针”并不足以证明配合成立。[官方整机照片与接口说明](https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32s31/esp-mosaico/user_guide.html)（查询 2026-10-19）。

纵向先采用“左侧接入、下部控制”的布置原则，机械验证比较两条实现路径：

1. **首选一块 L 形控制板**：左上连接器伸到 H2，板体沿左侧向下延伸至按键区。优点是没有额外板间线束；需确认连接器高度能使触点板与按键帽处在合适平面，且板颈和壳体有足够支承。
2. **空间不合适时改用小转接板＋短内部线束**：H2 转接板独立固定，下方按键板可调整高度。线束需防错、固定和留出装配空间；此方案会增加板间连接器和 BOM，当前未创建或接线。

横向优先评估带中央开口或下部连接桥的一体控制板；空间冲突时再拆分左右板。右手按键仍使用现有 H2 信号，不能直接改接右 H1，因为右侧与板载音频存在资源占用关系。

当前 J1 **C492427 是直排针电气原型候选**，并未换成弯排针。最终弯排针型号需在尺寸核对后确定，连接器变更必须同时更新母版、封装、BOM 和检查记录。已查到的 C3202442 商品页标为停售，不进入新 BOM；不为了填满采购表而采用停售料号。[商城页面](https://item.szlcsc.com/3764219.html)（查询 2026-10-19）。

## 硅胶按键怎样落实

主游戏区为 **四个方向触点＋A/B 两个触点**。十字键是一体塑料键帽，配中心支点与限位；允许相邻方向形成斜向，同时通过结构降低上下或左右同时压下的可能性。A/B 为各自独立的圆形键帽。Select/Start/Menu 暂按独立辅助键规划，结构类型可随同一套胶垫选择，尚未决定沿用任何轻触开关型号。

从手指到板面的配合关系如下：

```text
塑料键帽 → 壳体导向 / 十字键支点 / 行程限位
         → 硅胶弹性穹顶与导电粒 → PCB 两组触点 → 刚性支承
```

先找可取得图纸和样件的现成手柄胶垫与配套键帽，再围绕它设计壳体和触点；首轮不默认开定制模具。胶垫采购可能来自结构件供应商，不能虚构立创商城 C 编号。记录供应商、样品批次、图纸版本及可持续供货情况；实体电阻、连接器等仍单独核验商城来源。

| 配合项 | 冻结前必须得到的信息或结果 |
| --- | --- |
| 手感 | 实测或供应商给出的力—行程曲线、触发与回弹一致性；装入壳体后检查边缘按压、连按、卡键和噪声 |
| 十字键 | 中心支点高度、转动间隙、四向限位、斜向触发区域；不能靠胶垫自行保证互锁 |
| PCB 触点 | 导电粒直径、落点偏差、两电极图形、间隙及可生产的接触表面工艺；按胶垫和 PCB 厂要求确定，不直接套用轻触开关焊盘 |
| 板面与装配 | 接触区不能被阻焊覆盖；避免焊锡凸起、过孔和丝印干扰接触；胶垫定位与压紧结构保持一致 |
| 电气与软件 | 接触电阻范围、污染后低电平裕量、释放回高电平、按压抖动和去抖延迟；保留逐键及组合键诊断 |

导电胶不是理想零欧姆开关。当前电路的节点通过 10 kΩ 上拉，按下后经接触电阻到地；忽略 GPIO 漏电和内部上拉时，节点电压约为 `3.3 V × R接触 / (10 kΩ + R接触)`。串联 1 kΩ 在这一简化条件下基本没有压降；内部上拉、输入漏电及实际供电偏差需另计。必须用 ESP32-S31 对应电气阈值及实测最坏接触电阻复核，不能把现有轻触开关测试结果视为胶垫方案通过。

SW1–SW9 仍表示原型的九路常开开关，现有 C231644 仅用于电气验证。最终 SW1–SW6 将对应导电胶接触电极，胶垫、键帽进入结构 BOM；辅助键另行选型。只有完成上述配合后，才在母版关联自制触点器件与 PCB 封装，避免原理图、位号 BOM 和 PCB 相互矛盾。

## 扬声器、振动与固件

V1.2 官方资料已列出 BaseBoard 扬声器和 CoreBoard 振动马达，音频通过 ES8311 与 NS4150B，马达由 GPIO8 控制、高电平开启。套件复用这些板载器件，不向按键扩展板再添加一套。壳体需保留声孔及后部空间，并检查紧固结构是否引入异响。[官方硬件说明](https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32s31/esp-mosaico/user_guide.html)（查询 2026-10-19）。

现有诊断固件已有显示、测试音和按键页面，**尚无振动测试**。下一轮软件任务是使用固定版本 BSP 接口加入默认关闭、有限时长、退出时关断的振动诊断，并核对 USB／电池供电下的效果及声音、按键干扰。此处是待实现计划，不表示已经完成或烧录。

FC／GB 游戏不能据此自动获得振动效果；先为菜单确认等明确事件提供可关闭的反馈，游戏内振动需要运行时或游戏专门适配。横向和纵向共用逻辑键码，触点电气方案确定后仅调整输入适配与实测去抖参数。

## 下一轮的并行交付

| 顺序 | 硬件与结构交付 | 软件交付 | 汇合检查 |
| --- | --- | --- | --- |
| 1 | 登记主机尺寸、H2、屏幕窗口、USB/电源键位置、声孔、支承面；记录测量基准和误差 | 在现有工程进行板载显示、测试音与输入诊断；登记设备固件与恢复方式 | 现有主机是否正常，扩展板不能遮挡的区域明确 |
| 2 | 取得胶垫＋键帽样件和图纸，做纵向纸样／结构样；比较 L 形板与转接方案 | 增加振动诊断；测试输入继续推进首款 FC 测试内容 | 决定胶垫、弯排针型号、控制板平面与支承点 |
| 3 | 在 GamePlay V1.0 母版落实触点封装、板框、孔位与线路；更新 BOM、结构模型和检查记录 | 接入真实九键，调去抖与相反方向输入策略 | 逐键、斜向+A/B、快速连按、松手释放及声音/振动并行测试 |
| 4 | 纵向样机验证后，用相同输入约定推进横向结构和板卡方案 | 同一固件验证两种形态 | 分别记录握持、误触、装配与可靠性；不把纵向结果自动算作横向通过 |

尺寸表至少包括主机外廓与厚度、屏幕窗口、H2 相对外壳基准位置与插入深度、按键中心/行程、胶垫定位孔、支点与限位高度、控制板固定点以及各部件间隙。当前没有这些实测值，不能据此生成可制造板框。结构源文件和尺寸表按 [文件规划](README.md) 保存；电气核对继续用现有 `python tools/check-gamepad.py`。
