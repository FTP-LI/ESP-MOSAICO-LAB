## API 编辑结果

在嘉立创EDA 工程 `ESP-MOSAICO-LAB` 内，将原 `Schematic1 / P1` 改为 `gamepad-board-rev-0.1 / 01-buttons-and-host-interface`。原图只有 A4 图框，修改前快照留在 `eda/snapshots/`。通过 API 添加 28 个实体元件（J1、9 个开关、18 个电阻）、网络标记、说明文字和连线，保存并导出原生工程、原始页源码和网表。图框版本更新为 rev-0.1。

原理图布局为接口区加 3×3 按键电路区，不代表实际按键位置。按键与接口文字的位置已通过源数据复核。当前客户端的图像 API 会返回缓存画面，部分标签操作不兼容；未把缓存截图作为最终渲染证据。导线网络标签仍需在后续可可靠渲染的版本中检查排版，不能把源数据检查当作完整视觉验收。
