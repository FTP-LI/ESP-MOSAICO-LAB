查询日期：2026-10-19（Asia/Shanghai）。状态：`experimental`。本次修正“EDA 库中有器件就等于商城可采购”的错误假设。以下型号已写入母版、网表和 [BOM](bom.csv)，仅完成商品页面与库属性核对；未核实实时可售库存、交期或完成样品验证。

开关商品页面链接的 [厂家规格书](https://atta.szlcsc.com/upload/public/pdf/source/20180622/C231644_8E779A5E99ACC98584838CDB900BEA24.pdf) 标题为 `KAN0444-0201B5 定位柱`，与 `/102` 不同。本轮没有把这份 PDF 当作该候选的完整匹配证明。PCB 封装冻结前，需取得供应商确认的 `/102` 图纸，核对焊盘、孔位、端子配对及机械尺寸；若不匹配，应重新选型并更新原理图、BOM 和检查记录。该微型开关也尚未证明适合方向键手感。

J1 页面列出的配合针长为 6 mm、塑高 2.5 mm、端接针长 3 mm。这些是候选商品参数，不是当前主机的实测配合尺寸。只有主机的插接方向、公母、高度和针号经实物确认后，才能决定最终连接器及 PCB 安装方向。

API 精确料号查询用于取得器件的符号、封装、厂商型号和供应商属性；商城页面用于证明存在对应商品。两者都不能单独证明现货、机械匹配或打样可用。原来的逻辑动作名已移至 `GameAction` 属性和独立文字，器件 Name 保持型号或标准阻值，以便 BOM 与商城资料核对。

所有 28 个实体元件仍参与 BOM 和 PCB 转换，没有通过排除器件来消除标准化警告。历史 DRC 修复见 [复核记录](checks/2026-10-19-drc.md)，本次说明更新后的检查见 [形态决策记录](checks/2026-10-19-layout-decision.md)。当前**不可按此接线、采购装配或下单生产**；本轮未下单。
