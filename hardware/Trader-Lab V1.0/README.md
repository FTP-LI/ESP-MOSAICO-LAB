# Trader-Lab V1.0 硬件需求

独立 ESP-Mosaico 行情终端，不改动现有电路板。2026-10-27 已完成官方固件安装、独立联网／校时／真实报价、重启和 24 轮旋转／亮度自动检查；实体操作、提醒及完整硬件验收进展见 [实测记录](../../firmware/Trader-Lab%20V1.0/docs/HARDWARE-TEST-2026-10-27.md)。

- 主机：ESP32-S31 版 ESP-Mosaico，480×480 触控屏。
- Wi-Fi：独立联网获取行情和校时；USB 用于供电、调试和后续官方安装。
- IMU：四向画面旋转、可选翻转切页；平放保留上一方向。
- 扬声器/振动：可配置到价提醒与试听，音量和确认交互需实物测试。
- 电池管理（后续）：显示真实电量/充电状态，低电时减少后台请求；本轮尚未接入电量 UI，不沿用其他应用续航结论。
- 结构：桌面支撑与充电走线；联网温升、屏幕亮度、触摸角度及扬声器遮挡需要验证。

不增加麦克风录音或语音唤醒，不以常驻录音作为操作入口。电路、电源参数与续航以实际板卡及测量为准。
