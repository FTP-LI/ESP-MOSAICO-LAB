# Desk-Deck V1.0 硬件与结构需求

独立于 Time-Tick。机械结构仍为需求规划，首版复用 ESP-Mosaico 主机，不要求增加电路板；没有生成或修改原理图/PCB。2026-10-25 已安装独立固件进行板载功能调试，结果见 [实机记录](../../firmware/Desk-Deck%20V1.0/docs/HARDWARE-TEST-2026-10-25.md)。

## 板载资源用途

| 资源 | 计划用途 |
| --- | --- |
| 480×480 触摸屏 | 六键控制、场景选择与设置 |
| IMU | 四个立放方向的稳定识别、界面对正；平放保留状态 |
| USB | 主机供电、标准 HID 输入、官方调试/配置通道（共存待验证） |
| 振动马达 | 可关闭的短触觉反馈，不承担后台持续提醒 |
| AI/实体按键 | 后续评估作为锁定/唤醒入口；首版触屏流程不依赖它 |
| 电池/电量计 | 使用官方读数，作为拔线过渡；不在规划阶段承诺续航 |

## 桌面使用要求

- 数据线必须支持数据传输；电源连接与 HID 枚举是两种不同状态。
- 支撑件应能承受单指按压，不翻倒、不遮挡触屏边缘和 USB 插头。
- 旋转时保留线材弯曲余量，避免接口长期受力。优先验证现有外壳/软垫，再决定是否设计可旋转底座。
- 初期以 USB 桌面供电为主要场景；温升、充电、低亮度可读性要单独测量。
- 不改变官方 USB 接口和电源电路；若必须改底座或转接板，另行绘图、核对尺寸并验收。
