# Time-Tick V1.0 — 硬件

配套 [Time-Tick 软件](../../firmware/Time-Tick%20V1.0/README.md)的翻转计时器。首版复用 ESP-Mosaico CoreBoard V1.2 的板载资源；当前阶段为硬件需求与实测计划，尚无本项目外壳 CAD、PCB 或打样件。

| 功能 | 复用器件/资源 | 当前依据 |
| --- | --- | --- |
| 姿态识别 | BMI270 加速度计、陀螺仪 | 主机原理图与 BSP IMU API |
| 界面与设置 | 480×480 CO5300 屏幕、触摸 | BSP 支持屏幕及触摸同步旋转 |
| 到时提醒 | 板载振动电机 | BSP motor API |
| 声音反馈 | ES8311、板载扬声器 | 官方BSP codec API；代码已接入，待实测 |
| 按住语音入口 | ES8311、板载麦克风 | 本地音量检测；未接模型，待实测 |
| 时间天气 | ESP32-S31 Wi-Fi、联网校时 | 不依赖额外天气传感器 |
| 供电 | 主机现有供电方案 | 电池子板兼容性和续航待实测 |

板级资料与原始来源在 [ESP-Mosaico 硬件](../esp-mosaico/README.md)。不新增外接 IMU；代码通过“正放＋右转”校准建立坐标，不硬编码未经实测的安装轴向。当前主板版本检查只接受 V1.2。

## 结构要求

- 外壳提供正放、左右侧、倒置及屏幕朝上平放的五个稳定支撑面。每个支撑面的平面法向应接近对应传感器轴。
- 正放定义为屏幕可读、上边缘朝上的桌面姿态；该方向显示时间天气。校准后方向与具体外壳绑定，换装或改变安装方向需重新校准。
- 朝上平放由外壳或脚垫承重，保留平放前屏幕方向。朝上平放和屏幕朝下均不设置计时预设、不触发或重置计时，已有计时状态保持。避免玻璃直接接触桌面。
- 保留 USB、主机电源/BOOT 操作空间和散热位置，避免翻转时连接线拉扯。按钮、屏幕和扬声器位置以主机真实尺寸为准。
- 先复测主机长宽厚、接口和电池空间，再绘制本项目独立外壳；GamePlay 的结构尺寸仅作参考，不直接认定兼容。
